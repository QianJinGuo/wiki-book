04 / VLM JUDGE商品图文一致性：剪枝、蒸馏与成本实验

围绕 267 张真实商品图，比较纯文本、纯图像和图文输入，研究视觉 token、输出预算、服务并发，以及从 7B 教师到剪枝 + LoRA 学生模型的成本与可靠性。

  • 实验设计：固定正样本、跨类负样本、hard 子集与边界样本；从原始输出复算“正确 / 可解析 / 覆盖”三套口径。
  • 关键发现：文本臂在 hard 形态判别为 29/47，图像臂为 48/48；提示模型在部分样本上受标题文本偏见影响。
  • 工程结论：剪枝零样本解析率 0/267；教师响应蒸馏后恢复任务输出，但缺少 GT-only 对照，不能把收益全部归因给蒸馏。

03 / METHOD

我的工作方式

从问题发现到生产证据

01

定义损失

Frame

先找真实摩擦、金额、频率与可干预点，避免先选模型再找场景。

02

划分责任

Design

决定哪些交给模型、规则、检索或人工，明确失败时系统怎么处理。

03

构建闭环

Build

把能力接入交易、风险或数据链路，处理延迟、幂等、权限与回退。

04

建立证据

Prove

固定标签与切分，做回归、失败归因和消融；主动写清不能证明什么。

05

推进上线

Ship

从 Shadow / Canary 到全量，用业务指标、SLA 和运维成本做验收。

01

先写口径，再报结果

分母、可解析率、系统级结果与个人贡献分别说清楚，避免漂亮数字脱离证据。

02

把失败当成产品需求

弃答、HITL、降级和审计不是补丁，而是高风险 AI 正常工作的一部分。

03

保持模型外围的控制权

关键策略门禁留在模型外；模型输出建议，系统负责权限、约束和最终路由。

04

用快速原型降低不确定性

先用可运行切片验证合同，再根据真实失败扩展复杂度，减少大架构先行。
