# 豆包、WorkBuddy、QoderWork怎么选？我用8个真实办公任务把三家桌面Agent测明白了

> 来源：夕小瑶科技说 (WeChat) | 2026-07-14 | v×c=56
> 核心观点：三家国产桌面 Agent（豆包/WorkBuddy/QoderWork）各有侧重——豆包是封闭套装（强多模态+语音），QoderWork 是专业 Agent 市场（硬核 Skill 生态），WorkBuddy 是开放连接器（外接模型+IM 全接入）。

## 摘要

文章通过 8 个真实办公任务（本地电脑操控、信息搜索整合、跨设备协同、多模态、Skill/MCP 生态、外接模型、语音通话与屏幕共享、价格透明度）横评了三家国产桌面 Agent：豆包（字节）、WorkBuddy（腾讯）、QoderWork（阿里）。评测发现三家没有全能冠军，但各自有清晰的定位分工。豆包在 PPT 制作和多模态能力上表现突出，但生态封闭（仅飞书 IM、仅豆包模型）；QoderWork 在微信提醒、专家 Skill 套件上最强，适合专业场景；WorkBuddy 最开放（外接模型、全 IM 接入、费用预估），但电脑操控能力较弱。

## 核心要点

- **本地电脑操控**：豆包和 QoderWork 打平，均能流畅操作浏览器和本地软件；WorkBuddy 默认绕过 Computer Use 能力，改用手写代码方式执行任务，速度明显慢
- **信息搜索整合**：豆包效率最高（并行搜索+快速产出），WorkBuddy 深度最强（HTML 报告+独家数据），QoderWork 最简练（老板摘要风格）；但三家都有事实盲区，人工核查不可省
- **PPT 制作**：豆包视觉最好（排版美观、图表丰富），QoderWork 清爽但内容偏薄，WorkBuddy 内容扎实但版式老派、有渲染问题
- **跨设备协同**：WorkBuddy IM 生态最全（微信/企微/钉钉/飞书），QoderWork 次之（三大 IM），豆包仅支持飞书且接入体验差
- **微信提醒测试**：仅 QoderWork 成功通过微信通知完成饮水提醒；WorkBuddy 和豆包仅聊天框内通知
- **多模态能力**：豆包一家独秀（Seedream 图像+Seedance 视频），QoderWork 无视频生成，WorkBuddy 支持 5 秒视频但效果一般
- **Skill/MCP 生态**：QoderWork 走「市场模式」、有专家套件；WorkBuddy 走「腾讯全家桶」、生活办公场景；豆包用「/」唤起技能、无集中管理面板
- **外接模型**：仅 WorkBuddy 支持自定义外接模型（OpenAI 兼容协议）；QoderWork 支持多款国产模型但不支持外接；豆包仅支持自家模型
- **语音共享屏幕**：豆包独有功能，可边通话边共享屏幕，适合远程帮助
- **价格**：QoderWork 社区版免费（Pro 59元/月 2000 Credits），豆包 68-500 元/月三档，WorkBuddy 99元/月起（白嫖积分最多）
- **积分非同一货币**：同一任务三家消耗天差地别，建议用免费额度跑真实任务再付费

## 深度分析

### 桌面 Agent 的分化趋势

评测揭示了国内桌面 Agent 的三种路线：**豆包**走「强模型+多模态封闭系统」路线，体验最连贯但生态壁垒最高；**QoderWork**走「Agent 即工具市场」路线，专业度最高但上手门槛也高；**WorkBuddy**走「生态连接器」路线，开放度最高但自身操控短板明显。

### 关键能力缺口

在信息搜索整合维度，三家均出现了事实错误（公司转行未识别、汇率算错、模型版本滞后），说明桌面 Agent 目前还不能完全替代人工调研。这个领域的瓶颈不在于操作能力，而在于搜索理解和时效性判断。

### Skill 生态的三种模式

QoderWork 的「下载量排名+专家套件」反映了 B 端专业场景需求，WorkBuddy 的「腾讯全家桶+场景分类」偏向日常办公，豆包的「/唤起+自定义」最为轻量但缺乏发现和治理机制。
