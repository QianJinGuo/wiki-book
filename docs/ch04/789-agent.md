# Agent 自进化四齿飞轮：评测→记忆→落地→控制

> 腾讯技术工程（yannisyang、ethanytzhou）基于 Anthropic 递归自改进报告、斯坦福 CS329A 课程、EvoAgentX 等开源框架研读，提炼出「评测→记忆→落地→控制」四齿飞轮方法论——不是单个环节最佳实践，而是一个完整、可落地、经过验证的工程闭环。

## 核心洞察：自进化瓶颈在环节衔接

Agent 上线半年后仍会犯三个月前犯过的错、走三个月前走过的弯路——问题不在模型不够强，而在没有人给它搭一条从「做过」到「记住」到「变好」的路。评测、记忆、Self-Improve 三件事在多数团队被拆散着做：评测分数去了周报而非 Prompt/Skill 改进链路；记忆向量检索噪声太高反被干扰最后被默默关掉；Self-Improve 生成的 Skill 质量参差、无评测筛选、无版本回滚。

**自进化的瓶颈不是任何一个技术点，而是环节之间的衔接。** 评测信号必须流进记忆和 Skill 更新；更新后必须能被评测验证；验证结果必须反哺下一轮进化——链路断任何一环，飞轮都转不起来。

## 四齿飞轮结构

- **评测**是闭环的「眼睛」（感知哪里有问题）——评测可信度 > 系统复杂度；一个简单但评测可信的系统远好于复杂但评测失真的系统；错误的正反馈会让 Agent 加速开往悬崖
- **记忆**是闭环的「大脑」（积累可复用经验）——记忆系统核心不是存储能力而是治理能力：版本控制、主动遗忘、冲突解决、来源溯源这些「不性感」的治理能力才决定记忆是帮忙还是添乱
- **Self-Improve / 落地**是闭环的「手脚」（把经验变成实际改进）
- **人机协作**是闭环的「方向盘和刹车」（确保进化方向不跑偏）
