# ComBodied Agents：以人为中心的 Agentic AI 新范式（伴身智能体）

> **Background**：本文基于机器之心 2026-08-25 对论文《ComBodied Agents: a New Paradigm of Human-Centric Agentic AI》的报道。论文由 Mila、蒙特利尔大学、A*STAR、牛津大学、剑桥大学、清华大学等 16 家高校与科研机构的 22 位研究者提出，第一作者丁强刚（蒙特利尔大学博士生、Mila 成员、弦指科技创始人）。

## 核心洞察：任务完成得更好 ≠ 让人长期变得更好

今天最主流的两类 Agent 围绕外部任务组织能力：数字智能体（Digital Agents）操作网页、代码、API 和工作流，改变数字世界的状态；具身智能体（Embodied Agents）感知、导航和操控物体，改变物理世界的状态。它们都在追求更长的任务链、更高的成功率和更少的人类介入。

但当 AI 进入健康、学习、陪伴和个人生活管理场景时，仅仅「把事做完」已经不够——AI 可能替用户写出更好的文档，却没让用户获得更深的理解；可能加速一次决策，却削弱用户判断依据、质疑建议和独立行动的能力。

## 结构性缺口

一个老人漏服药的场景暴露了这个缺口：数字智能体可以发一次提醒，具身智能体可以把药送到面前，但两个动作都没有回答——老人是忘了还是没看懂医嘱？是副作用还是主动拒绝？下一步该提醒、解释、联系家属、转交医生，还是尊重他的选择暂时不做？

这类问题指向当前 Agentic AI 的**结构性缺口**：围绕人的长期状态与主体性来构建 Agent，而不是围绕外部任务。

## ComBodied Agents 范式要点

- 以人为中心（human-centric）：围绕用户的长期状态、能力成长与主体性组织 Agent 行为
- 伴身（companion）：Agent 长期陪伴用户，理解其意图、状态与偏好
- 从「替人完成任务」转向「让人长期变得更好」

论文推动该范式从研究框架走向 AI 硬件实践（如弦指科技 Zilo Ring 智能戒指）。
