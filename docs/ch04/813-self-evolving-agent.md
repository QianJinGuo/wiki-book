# Self-Evolving Agent：自进化的隐藏陷阱

大家都在教 AI Agent 从错误中学习。但我们发现了一个很反直觉的现象：它可能越来越会做"见过的题"，却越来越不会做"没见过的新题"。这就像把每道错题的答案都背进错题本——分数看起来提高了，但真正的能力没有提升。
