# Built Technologies AI Document Intelligence — 房地产金融 AI 文档处理引擎

Built Technologies（房地产金融软件提供商，处理超 5000 亿美元项目）基于 Amazon Bedrock 和 AWS IDP（智能文档处理）加速器构建了 AI 文档处理引擎，服务于房地产全生命周期的 Agentic 产品。

## 业务场景

房地产金融运行在文档之上：提款包、贷款协议、发票、保险证书、检查报告等。每个文档包含贷款方和干系人需要审查、验证和行动的信息。这些文档通常冗长、格式不一致、领域专深且处理困难。

## 架构方案

引擎基于 Bedrock 的 LLM 能力结合 AWS IDP Accelerator 的文档处理管线，实现：
- 多类型文档的自动分类和提取
- 领域特定信息的结构化输出
- Agentic 产品的基础文档智能服务

## 行业价值

AI 文档处理在此场景中替代高度人工、手动的流程，影响了关键业务决策的规模和速度。该方法为其他文档密集型行业（法律、保险、医疗）提供了可复用的参考架构。
