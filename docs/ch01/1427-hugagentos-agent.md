# HugAgentOS — 浙大三引擎一体自进化 Agent 操作系统

> 新智元 2026-08-11。浙大开源 HugAgentOS：解决 Agent 不自主积累、不自进化的问题——同一类任务执行十次，第十一次仍从零规划；被纠正的错误下次照旧。

## 核心能力

- **三引擎一体**：规划/执行/进化的自进化架构
- **每步可归因**：执行轨迹可溯源到具体决策
- **可回放/可回滚**：经验可重放、错误操作可撤销

与 [Agent 记忆架构](../ch04/508-perplexity-brain-self-improving-agent-memory-architecture.html) 及 [openJiuwen 自进化记忆](../ch06/034-openjiuwen-autogenetic-memory-agent.html) 属同一研究命题：Agent 经验沉淀与自进化。开源定位使其成为可复现参照实现。
