## How the site works

- **Sources**: 4,000+ first-hand articles (papers, engineering blogs, post-mortems) collected and deduplicated daily; 1,700+ curated entries so far, still growing.
- **Difficulty ratings**: every entry is graded ⭐ to ⭐⭐⭐⭐⭐, so you can read at your own level.
- **Traceability**: every curated entry links back to its primary source — the site is a map, not a replacement.
- **Self-evolving**: an automated loop collects, filters and re-integrates new material every day.

## Suggested learning path

| Level | Identity goal | You can... |
|---|---|---|
| Level 1 · Beginner | Agent novice | Explain what an Agent is — and what it is not; build a minimal CLI Agent |
| Level 2 · Engineer | Agent engineer | Make Agents execute tasks reliably: tools, RAG, memory |
| Level 3 · Expert | Production engineer | Ship to production: observability, evaluation, governance, cost control |
| Level 4 · Scientist | Research engineer | Make Agents improve themselves: self-evolution experiments, paper reproduction, benchmarks |
| Level 5 · Master | Domain master | Form your own methodology: open-source work, writing, system-design portfolio |

The full path (in Chinese, with a weekly cadence and deliverables per level) is described in [学习路径 · Learning Path](/PATH.html).
