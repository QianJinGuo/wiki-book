# 向量库该不该存在于记忆层？

> 🧭 综合·争议 | 信源 5 篇

<!-- syn-slug: vectordb-in-memory-debate -->

这是本章内部最尖锐、也最诚实的分歧：分层派的架构图里向量库是标配，而一篇读完两套主流 Agent 记忆源码的条目得出了相反的怀疑。剪藏式的各说各话在这里没有出路——把立场摆上桌，是编者能做的最少的事。

## 编者裁断

**介质之争目前是个伪问题，真问题是写入纪律与审计。** 源码实证派的证据最硬：两套被大规模使用的系统都没有把向量库放在记忆链路的关键路径上，这至少说明"标配论"不成立。但编者同样不同意"向量库无用"的强版本——它只是把问题的优先级排错了：先有写入纪律（记什么、记成什么格式、何时过期），介质选择才成为一个可以推迟的技术细节。
