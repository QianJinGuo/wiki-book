# 经验自进化：自动挖掘经验资产，消融实验验证真实收益丨AgentLoop 数据飞轮实践（五）

> 阿里云云原生 / 马云雷，AgentLoop 数据飞轮实践系列第 5 篇（也是最后一篇）。前四篇走通"人类专家驱动"调优闭环，本篇补上数据飞轮最自动化的一块：**经验库**——让 Agent 从自己历史运行中自动沉淀经验，越跑越好。并用消融实验回答：经验注入到底有没有用、怎么用收益最大。

## 经验库核心机制

算法自动从 Agent 运行轨迹中挖掘成功模式和失败模式，沉淀成经验资产。建立在一个朴素观察上：**Agent 的每一次运行都应为其后续运行积累经验**——同一个坑第一次踩可原谅，第一百次还踩就是浪费。经验库把"踩坑/走通"历史变成可复用知识：成功模式告诉 Agent 怎么做，失败模式告诉 Agent 别怎么做；经验以上下文注入方式进入 Agent 运行过程。

经验库挖掘的是**通用 Agent 领域的常见优化手段**：工具调用执行情况、延时、执行准确率、执行路径等通用场景。这些维度不依赖具体业务，任何 Agent 都反复遇到。

## 挖掘与集成实操

- **前提**：数据接入完成（见第 2 篇）——没有轨迹数据，挖掘是无米之炊。
- **创建经验库**：选择应用 → 命名 → 设置挖掘起始时间（设早可挖掘更多轨迹）。
- **挖掘结果全程可追溯**：演示挖出 4 条经验，每条含内容、适用场景、来源 Trace——经验不是黑箱结论，每一条都能回查出处，对调优排障重要。

### Agent 侧集成（4 步）

1. 创建 API Key（Agent 访问经验库的凭证）。
2. 安装 Skill：`alibabacloud-agentloop-experience`（进入 Agent 目录执行安装命令）。
3. 把经验库信息写进 env 配置（告诉 Skill 去哪个经验库检索）。
4. **权限条件**（易漏）：白名单、Shell 权限、allow shell 三者缺一，召回就不会发生。

### 召回验证

向 Agent 提问『AgentLoop 如何使用经验库』『当前经验列表里有哪些内容』可验证召回成功。**召回是有判断的**：相关问题召回对应经验、无类似经验不召回——"宁缺毋滥"设计防止无关/错误经验误导 Agent。

换 Session ID 重新发起同一请求可对比执行过程：该请求原走 12 步左右，注入经验后步骤显著减少（经验绕过试错环节）。

## 消融实验：经验注入策略选优

通用优化手段之外，真实业务总有自定义需求——**经验的注入方式（召回多少、放在哪、怎么呈现）直接影响效果，甚至可能帮倒忙**。真正部署前要做召回测试，找到最佳策略。演示以无经验为基线做一轮消融实验。

**要调的参数**（消融实验对照维度）：
1. 召回阈值（多相关的经验才召回）
2. 注入条数（召回多少条）
3. 注入位置（放在上下文哪里）
4. 呈现方式（怎么呈现经验）
5. （无经验基线对照）

每一个参数都是一次"注入经验 vs 不注入/换种注入"的对照——**逐个因素拆开验证**，而非笼统说"加了经验会更好"。

## 消融实验效果（选定策略 vs 基线）

| 指标 | 相比基线 |
|---|---|
| 耗时 | 降低 30%~40% |
| 成本 | 降低 20%~47% |
| Token 消耗 | 大幅下降 |
| 工具调用 | 大幅减少 |

选定策略并删掉实验无关信息与内部标识符后的效果：**耗时降低 30%~40%、成本降低 20%~47%**，Token 消耗大幅下降、工具调用大幅减少。
