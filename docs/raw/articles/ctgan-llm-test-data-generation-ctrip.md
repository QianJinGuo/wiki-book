# AI专栏 | 别再手动造数据了！LLM 与 CTGAN 组合拳破解测试数据难题

**作者:** 携程技术
**时间:** 2026年7月23日 17:00

作者简介：Flint Liu，携程测试开发总监，对于测试用例生成、基于模型的测试、质量领域体系建设以及AI Test有一定的理论和实践积累。Aquawer，携程高级测试开发工程师，专注于软件测试与质量保障领域，持续探索大模型在测试领域的应用。

导读：测试人员44%的时间耗在数据构造上——合成数据本是"解药"，但市面方案总缺一角：CTGAN丰富度高却学不会字段逻辑，LLM语义强但输出不可控且低效。本文提出CTGAN+LLM的工程化方案，让二者各司其职，实验证明字段间关系大幅提升，覆盖率接近100%。

## 一、背景

在软件测试过程中，构造测试数据是一项基础而关键的工作，其目的在于确保软件产品在多种条件下的功能正确性、性能稳定性和兼容性。随着软件系统发展，业务系统的复杂度大幅提升，测试数据的构造也面临高效性、安全性和充分性的挑战。

Capgemini与Sogeti的一项联合研究表明，测试人员通常需要耗费44%的测试时间用于测试数据的生成与管理，这是制约企业将产品快速推向市场以保持竞争力的一个关键因素。

常见的测试数据构造方式主要有两种方式，即手动创建测试数据或从线上数据库中同步可用数据。但前者通常成本较高，且受限于测试人员对于业务的理解程度；后者将会带来一定的隐私合规风险，且数据形态受限于现有业务场景，可能无法覆盖极端测试用例。

为了弥补上述两种方式在特定场景下的劣势，一些公司和研究机构提出一种新的概念，**合成数据（Synthetic Data）**。合成数据是指通过统计、深度学习、大语言模型等方式，将模型拟合到真实数据集，然后使用该模型生成不包含任何敏感信息的高度逼真的模拟数据。

> 注：合成数据可能是多模态的，比如数据、音频以及视频等，本文只对表格数据（Tabular Data）进行讨论。

本文评估了当前业界常用的几种模型，包括高斯分布、TVAE、CTGAN以及LLM，最终提出了一种CTGAN与LLM相结合的数据生成方案。

## 二、合成数据模型调研

### 2.1 高斯模型
基于高斯模型的数据生成使用统计学对原始数据的分布进行建模。优势在于计算高效、理论基础坚实且参数可解释性强。局限：仅能捕捉线性相关性，无法建模复杂的非线性关系；长尾分布建模能力弱。

### 2.2 TVAE模型
基于TVAE的数据生成利用变分自编码器的生成能力，增加时序依赖建模。局限：潜在变量缺少语义解释；分类变量拟合效果差；长尾分布建模能力弱。

### 2.3 CTGAN
CTGAN是一种针对结构化表格数据设计的生成对抗网络，通过条件生成机制解决混合数据类型难题。优势：条件生成模式有效处理类别不平衡，枚举字段覆盖率显著优于其他模型。局限：无法有效捕捉多字段联合约束和字段间隐含逻辑，可解释性差。

### 2.4 LLM
LLM的语义理解能力和推理能力使其能够从字段名称和建表信息推测字段间语义联接。局限：数据丰富度损失、输出可控性差、复杂场景稳定性不足。

### 2.5 综合分析
LLM与CTGAN分别满足真实性与丰富度的诉求。CTGAN枚举字段覆盖率可达100%，LLM字段间关系指标显著优于其他模型。

## 三、LLM-CTGAN数据生成方案

方案包括关联关系识别、数据生成、指标监控以及数据修复四个模块。

### 3.1 关联关系识别
为LLM提供少量数据样本和建表信息，将库表字段分为存在相关性的字段和关系独立的字段两部分。流程：1）LLM将字段分为若干个相关组；2）LLM批评并修复结果；3）过滤枚举字段。

### 3.2 LLM-CTGAN模型实现
- CTGAN：使用线上10000条真实数据训练，分批训练策略解决内存问题，预保存模型参数字典实现0.16s/条的高效生成
- LLM：使用从10000条压缩至1000条的数据，按字段分组分别生成，自部署Deepseek-R1-Friday（671B）

### 3.3 实验验证
对比CTGAN基线与LLM-CTGAN增强方案。行级指标和列级指标共同验证方案有效性。

### 3.4 数据整合与修复
后置检查：数据丰富度修复 + 取值异常修复。使用规则有效性验证确保数据质量。

## 四、总结与展望

AI增强的自动化数据生成方式能有效提升传统方法的效果。未来方向：复杂表间关系识别、效率提升与成本优化、通用平台建设。
