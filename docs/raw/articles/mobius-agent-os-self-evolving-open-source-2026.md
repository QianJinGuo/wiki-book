# 告别预制 AI：会生长、可进化的 Agent OS，开源了！

> AI寒武纪（YAR师）编译/介绍 Mobius Agent OS（GitHub: https://github.com/mobius-system/mobius），第一个具备自进化能力的 Agent 操作系统。

## 定位

Mobius（莫比乌斯）——目前第一个具备自进化能力的 Agent 操作系统。系统里的 Agent 不光干活，还能改造系统本身：界面不顺眼圈出来吐槽一句，它自己改自己。Vibe Coding + 7*24 小时持续工作是基础能力，Auto Research 系统、跨设备/OS 隔阂击破、自进化能力是其卖点。网页端、桌面端、命令行客户端、手机端任意形态使用。

## 多 Agent 管理

- 同时鞭策几十甚至上百个 Codex / Claude Code Agent 协同工作。
- **会话地图**：一览正在工作/休眠/待命的所有智能体。
- **会话挂项目**（而非挂终端窗口）：历史会话按关键词搜索、一键跳回、让原 Agent 接着干——解决"窗口关了上下文找不回"问题。按几十上百个 Agent 并行设计，每个 Agent 归属项目/任务在图上标清。

## Skill 和 Memory 管理

- **两层分离**：用户级 Skill/Memory 跟着人走（每个 Agent 继承创建者偏好）；项目级跟着项目走（不影响无关工作区）。团队内技能可直接共享。
- **"强调"按钮**：Agent 忘掉关键记忆时点一下，把那条规矩重新加载进来，不用重打要求。
- **追加 Skill** 操作。

## 全平台接入

网页、桌面、手机、终端用同一个系统：

- **小莫**（自然语言助手）：建项目、拆任务、启动 Agent、查进度都靠对话完成；界面能点的操作它代劳，界面做不到的也能处理，支持语音输入。
- **手机 App**：连接自己的 Mobius 服务器，项目列表/Agent 会话/实时进度/历史消息/语音播报/消息提醒；群聊频道可直接叫出 AI Agent 整理结论、创建任务、跟进进度。
- **桌面端**：多个项目和 Agent 集中在同一工作台，小莫统一调度。
- **TUI**：Windows 一行 PowerShell（install-v15.ps1），Linux/macOS 一行 npm（@mobius-os/mobius）。终端每个会话底部有可点击 Web 地址，点一下同一会话跳到网页端继续；离开电脑用手机打开，任务和上下文还在。

## 多智能体协作

- **跨智能体**：①手动控制跨会话连接——只读模式 @ Agent 读取另一会话完整上下文（不干预不唤醒）；交流模式在两 Agent 间建双向沟通渠道直接交换信息共同推进。②依托研究子系统构建**智能体群**：群内 Agent 通过共享"群黑板"自主通讯、协同分工。@ 连接适合临时互通，智能体群适合复杂、开放、持续协作任务。
- **跨设备（aimux）**：云服务器、工作站、笔记本、嵌入式设备都能接入且不受 OS 限制。示例：手机发指令→服务器训练神经网络→完成后下载到无人车/无人机→上班用 Mac 以 LaTeX 整理实验报告，全链路自动跑完。
- 模型和 Harness 不写死：GLM、GPT、Claude、DeepSeek 可接；Claude Code、Codex 等 Harness 统一调度。

## 自进化实现

- **设计师之眼模式**（Ctrl+Shift+E）：圈选界面元素 + 输入一句要求（如"这两个元素没适配暗色主题，那个卡片高度应跟随文本长度"）→ 启动自进化。
- 要求被自动拆成多条改造任务，每条任务派一个 Agent：定位元素→修改代码→验证效果→提交部署，全程无人参与。
- 越用越像自己的系统：界面布局、工作流程按个人习惯改出差异。

## 工作布局（一键切换）

- AI 副驾流：逐行审核 Agent 修改，适合需要人持续把关的任务。
- 全军出击流：一次多任务并行执行、各自验证后合并结果。
- 云端漫游流：调度多台云服务器/集群，文件数据云端流转。
- 办公流：上传文章/网址/表格/图片/财报/课题，AI 分析总结创作绘图剪视频。
- 科研流：多 Agent 拆解课题、展示过程、无人值守持续推进。
- 精简模式：轻量日常任务。

## 安装与总结

服务端一行 Docker 命令；启动后网页端配置模型。Windows 桌面端下载 zip 即用。哲学主张："预制 AI"问题——不是让所有人适应同一套冻结的产品，而是每人拥有一套由自己定义、持续扩展、不断进化的 Agent OS；系统、数据、工作方式和进化方向掌握在自己手里。开源、可私有化部署。
