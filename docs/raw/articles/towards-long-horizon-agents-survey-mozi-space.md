中国人民大学联合北京大学、清华大学、中山大学、香港科技大学、新加坡国立大学等发布 149 页综述《Towards Long-Horizon Agents: A Survey》，系统梳理长程智能体的定义、演进路径、工程架构、训练优化与应用挑战。

## 基础概念拆解：三大误区
1. 长程 ≠ 长时间运行：核心是大量相互依赖的决策链，而非运行时长
2. 长程 ≠ 自主智能体：自主性衡量人类介入程度，长程衡量长链推理可靠性
3. 长程 ≠ 自进化智能体：自进化是长程最高阶能力（H3），大量长程智能体不具备自进化

## H1/H2/H3 分级体系
- H1 单上下文任务（分钟级）：ReAct 为代表
- H2 跨上下文任务（小时至天级）：MemGPT、MemoryBank
- H3 跨任务开放式流（持续）：自进化 Agent 专属

## 三大瓶颈
1. 目标漂移与误差累积
2. 上下文腐化（中间遗忘效应）
3. 稀疏延迟奖励 + 不可逆操作

## 三阶段演进
1. Prompt Engineering (2020-2023)：仅 C1 能力
2. Context Engineering (2023-2025)：C1 + 部分 C2
3. Runtime Harness (2025至今)：C1/C2 成熟，部分 C3

## 双支柱架构

### 外部调度框架 Harness 六大组件
1. 循环与工作流
2. 上下文与记忆
3. 工具、MCP 与技能
4. 编排系统
5. Hooks 与中间件
6. 验证机制

### 内部模型优化七大训练链路
1. 架构基础
2. 数据与环境合成
3. 预训练与中期训练
4. 微调
5. 智能体强化学习
6. 同策略蒸馏
7. 自进化

## 五大落地应用赛道
软件工程 Agent / 信息检索 Agent / 计算机 GUI 智能体 / 多模态长程智能体 / 通用全能 Agent

## 四大前沿开放挑战
进化维度（自进化与跨框架迁移）/ 有效性维度（真实世界可靠交互）/ 效率维度（算力/上下文/模态成本管控）/ 可信维度（长周期安全与鲁棒性）
