# 微信公众平台


Kimi 如约在 27 号放出了 K3 的权重，值得关注的一些点：  
  
1\. 2.78 万亿参数，激活 104.2B，896 个专家里激活 16 个，100 万上下文，原生视觉。  
全球第一个开源的 3T 级模型，且过去 12 个月里有 9 个月，开源模型的最大尺寸都来自 Kimi。  
  
2\. 授权叫 Kimi K3 License，不是 MIT。Kimi 一路过来的授权路径是：MIT、Modified MIT，到了这次的 Kimi K3 License。  
MaaS 服务连续 12 个月合计收入过 2000 万美元，商用之前得先跟月之暗面单独签协议。  
自己产品中使用的，若月收入过 2000 万美元或者用户过 1 亿，界面上必须显著展示「Kimi K3」；内部自用则豁免。  
  
3\. 各服务商（如 Baseten 和 Fireworks）报价均统一为每百万 token 输入 3 美元、输出 15 美元，与 Kimi 官方 API 一致。  
原因在于官方有份单独的协议中有可售价格的限制，推测是要求不能比官方低。于是大家便没法拼价格了，只能转去拼延迟和吞吐。  
  
4\. 硬件方面，由于 MXFP4 权重的下载要 1.4 到 1.5 TB，所以 8 张 A100 只有 640GB 装不下，8 张 H200 则是 1.13TB 还是不够，8 张 B300 约 2.3TB，才是唯一塞得下的单节点机器……  
  
5\. 按 token 算 K3 非常便宜，BrowseComp 单次任务成本只有 GPT-5.6 Sol 的一半，比 Fable 5 便宜近一个数量级。  
  
6\. 技术报告里没写训练 K3 用了多少 token、烧了多少算力（K2 有写）。有估算这次超过 2e25 FLOPs，大概在 3 到 4e25，是中国训过的最大的模型。  
  
7\. 模型卡里有声明 K3 的短板：思考历史可能会被 agent 框架截断，导致效果变差；在场景有歧义时 K3 会倾向于直接动手而不回头问；虽然跑分接近，但聊天体验方面 K3 仍然落后 Fable 5 和 Sol。  
  
8\. 同一天 Dario 发了《我们对开放权重模型的立场》，说 Anthropic 从没主张过禁止开放权重，但所有足够强的模型不分开源闭源，发布前都该强制做安全测试。  
有人追问：中国的实验室要是不接受呢？  
  
9\. K3 是目前最大的开放权重模型，同时也是最不允许打价格战的开放权重模型——以后的开源发布，或许都会走 K3 这条路：自用免费，开云服务赚钱则需要瓜分利润，这或许是开源模型第一次能养活自己的商业模式。  
有预测称：模型训练和推理在商业上将会被拆开，就像半导体的设计与制造分离一样，Kimi 可能是第一家做 fabless 的模型公司。
