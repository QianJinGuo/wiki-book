# 中科大：大规模扩展下 RAG 智能体并不优秀——RAG 扩展评测研究

> 原始来源：https://www.xiaohongshu.com/explore/6a6bf4180000000026037cba
> 作者：每日ComputerScience（小红书论文解读号，2026-08）
> 论文：arXiv 2607.26497

## 研究问题

系统比较了不同检索增强生成（RAG）范式在**大规模语料库增长**下的表现，解决了现有 RAG 评测通常只在单一规模、不同设置下比较、无法判断技术随数据规模变化趋势的问题。

**核心发现：RAG 系统不存在绝对赢家。** 智能体检索在小规模数据中表现突出，但随着企业级知识库扩大，传统 BM25 凭借稳定的全局候选排序能力反超并保持优势——为大规模 RAG 部署提供重要参考。

## 核心亮点

### 1. 大规模 RAG 扩展评测

构建 **28 级嵌套语料规模梯度**，从 1,144 个文档扩展至 511,959 个文档（约 **450 倍增长**），固定问题、真实证据和干扰文档，公平比较不同 RAG 方案。

### 2. BM25 实现规模反超

- 文件系统智能体在小规模数据中领先
- 约 **1000 万 token** 规模后，BM25 超过智能体
- 在完整 **601M token** 语料库中保持近 **20 分**优势

### 3. 智能体检索机制重新定位

智能体推理能力**并不能替代高效候选发现**。将智能体接入 BM25 检索后，完整规模得分从 **36.9 提升至 69.4**，同时查询成本降低约**九倍**——推理的价值在于利用好候选，而非替代候选发现。

### 4. 揭示图 RAG 扩展瓶颈

GraphRAG、LightRAG、HippoRAG 等方法面临**索引构建成本**问题：大规模场景下 LLM 生成实体关系导致构建成本快速增长。

### 5. 统一成本-效果分析体系

同时衡量准确率、构建 token、查询 token 和延迟，证明 **BM25 在企业级知识库场景具有最佳成本收益比**。

## 意义

反直觉结论：在 RAG 中"智能体化"不等于"规模化友好"——小规模数据中智能体检索的优势会在企业级语料规模下被 BM25 的确定性全局排序反超。对大规模 RAG 部署的启示：先保证候选发现层的高效（BM25 级），再用智能体在候选上做推理，是成本收益比最优的组合（36.9→69.4 + 9 倍成本降低正是"BM25 候选 + 智能体推理"的实证）。
