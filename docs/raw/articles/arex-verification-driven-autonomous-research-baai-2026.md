# 智源AREX自主研究智能体：从「盲目搜索」到「验证驱动」

> 新智元报道。智源研究院 AREX 自主研究智能体：发现—验证不对称性 + 双循环递归求解框架。项目主页: https://vectorspacelab.github.io/arex-model/ | 模型权重: https://huggingface.co/collections/BAAI/arex | 体验链接: https://arex-research.com

## 核心思想：发现—验证不对称性

自主研究面对的是一组相互关联、彼此制约的条件。智能体不仅要从庞大的信息空间中定位候选答案，还需整合分散甚至冲突的证据，并确认最终答案满足全部关键约束——只要有一项未验证，答案即为无效解。自主研究的核心难题不是「搜索得还不够久或者证据难找」，而是：智能体能不能知道当前答案到底已经成立了什么、还缺什么，以及下一步最应该研究什么。

AREX 抓住的关键突破口是「发现—验证不对称性」：完整答案往往难以一次性生成，但一旦形成候选解，便可以通过针对关键约束的逐项验证，快速定位不足并指导后续探索。验证的意义不仅在于判断答案是否正确，更重要的是帮助智能体理解「已经知道什么、还缺少什么，以及下一步应该研究什么」。

## 双循环递归求解框架

AREX 的目标是训练能长期运行、自我验证、持续修正的研究型智能体——不是一次性给出答案，而是在「研究→验证→再研究」的循环中不断接近完整解。自我改进不是在线更新参数，而是智能体对自身研究状态和当前答案进行持续修正。

- **内层循环 Research Loop**：完成一轮相对完整的研究——搜索信息、调用工具、收集证据、比较候选，构造一个结构完整、证据可追踪、后续可审计的暂定答案。第一轮面对原始问题，后续轮面对被外层重新定义过的更聚焦新问题（补齐缺失证据、消解来源矛盾、替换不满足全部条件的候选）。
- **外层循环 Self-Improvement Loop**：依据任务约束对暂定答案逐项审计，形成约束级别置信判断（哪些条件已获充分支持/仍不确定/缺证据/需重研）。全部必要条件满足 → 结束输出；否则把未解决条件转化为下一轮内层循环的研究目标——明确告诉内层循环"已经解决了什么，接下来只需要解决什么"，每轮递归继承已有成果而非从头开始。

## 机制分析：自主上下文更新（ACU）

内层研究循环负责搜索、访问网页、验证证据、更新上下文并生成暂定答案；外层自我改进循环根据答案、证据和置信度决定接受、继续细化或重新开始。其中**自主上下文更新（ACU）是关键**：它不是普通摘要，而是面向下一步行动的研究状态——保留已验证发现、已排除候选、未解决约束和下一步计划。

BrowseComp 分析显示 AREX 通常主动更新上下文，而不是等到 128K 上下文窗口塞满后才被动压缩。受控实验：AREX 完整系统在 BrowseComp 上 82.5，比关闭 ACU 和外层循环的版本高出 22.9 个百分点。

长程研究不「失忆」：随着交互轨迹变长，历史记录同时包含已验证证据、被推翻假设、中途放弃计划与大量重复信息。全盘保留易迷失方向，简单截断又可能丢关键线索。AREX 让模型主动调用上下文更新工具，把交互历史整理成「研究进度表」：当前研究到哪了、什么已成立、什么已被排除、接下来最该查什么。

## 构造可验证的训练数据

从确定答案出发生成可验证研究轨迹：

1. 先从一个确定的实体答案出发，围绕它构造一组必须被真实证据支撑的约束条件
2. 把这些约束改写为无法通过关键词直接命中的开放式问题——迫使模型真正去搜索、比对和验证
3. 强教师模型在同样工具环境中完整执行这些任务，留下全过程研究轨迹
4. 但凡出现直接猜答案、忽略观察、证据不足或结论与证据矛盾等情况，整条轨迹被剔除
5. 最终保留从不确定候选逐步走向可验证答案的研究轨迹

## 分阶段训练与关键步骤强化

- **渐进式多轮能力训练**：先建立稳定的工具交互能力，再进阶到长链推理、候选比较和困难问题求解；巩固论文研究、高难知识推理等专项能力，避免任务间能力相互干扰
- **关键步骤聚焦监督**：把训练信号集中到证据发现、路径否定与重定向、关键上下文更新等转折点
- **步骤感知强化学习**：继续优化长程决策策略

核心解释：长程研究中真正难的不是例行搜索和访问网页，而是在关键时刻做对决定——什么时候相信一个证据、什么时候放弃一个候选、什么时候重整上下文并改变搜索方向。

## 实验评估（10B 激活参数达到自主研究前沿水平）

六个基准：BrowseComp、DeepSearchQA、WideSearch-en、GAIA、xbench-2510、HLE with tools。

- **信息深度**（BrowseComp / xbench-2510）：AREX-Base 在 BrowseComp 82.5，接近 GPT-5.4、Kimi-K2.6、DeepSeek-V4-Pro 和 Claude Opus-4.6，超过 GLM-5 与 Qwen3.5-397B；xbench-2510 接近 MiroThinker-H1，优于 Qwen3.5-397B 与 DeepSeek-V4-Flash
- **信息广度**（WideSearch-en）：82.0 Item-F1，论文对比范围内最高，超越 Kimi-K2.6、DeepSeek-V4-Pro、GPT-5.4 等
- **深度与广度结合**（DeepSearchQA）：89.9 F1，超过 GPT-5.4、DeepSeek-V4-Pro 和 Qwen3.5-397B，接近 Claude Opus-4.6、Kimi-K2.6 和 Gemini-3.1-Pro
- **端到端**（GAIA / HLE with tools）：85.4 / 71.0 / 52.4（三项测试）；GAIA 超过 Kimi-K2.6、Gemini-3.1-Pro 和 Qwen3.5-397B；HLE 文本子集超过 GLM-5、DeepSeek-V4-Pro、Qwen3.5-397B 和 MiroThinker-H1

对比结论：与开源前沿模型在双方均报告的 BrowseComp、GAIA、WideSearch-en 和 HLE 文本子集上全部领先；与 DeepSeek-V4-Pro 比在 DeepSearchQA、WideSearch-en 和 HLE 文本子集更高；与 Kimi-K2.6 比在 GAIA 和 WideSearch-en 领先、BrowseComp 接近、xbench-2510 和 DeepSearchQA 有差距。AREX 以 10B 激活参数在深搜、广搜、端到端智能体和工具推理之间取得均衡综合竞争力。

**参数效率**：AREX-Base 总参数量 122B，每次推理仅激活 10B。相比同总参数量的 Qwen3.5-122B 在双方均报告指标上全部提升；相比 Qwen3.5-397B 在六项完整可比基准上全部领先。AREX-Turbo 仅 4B 参数，在多项指标上超过 Qwen3.5-35B、Quest-35B 和 Tongyi-DeepResearch-30B。

## AREX Research Platform

将自主研究能力封装为面向科研与产业用户的日常研究工具，针对三类信息形态提供独立入口：

- **资讯**：持续追踪指定领域内的每日动态；支持用户指定关注方向（如 Coding Agent、芯片行业进展）生成持续运行的专属资讯智能体，按设定频率完成检索、筛选与汇总——以「用户关注点」作为过滤维度，信息流由「按热度排序」转向「按相关性组织」
- **论文**：筛选高关注度的研究工作并支持深度理解
- **播客**：从长时段访谈中提取关键观点与行业趋势

每条资讯/论文/播客旁提供自主研究入口，一键调用 AREX 智能体，智能体已感知当前阅读内容与上下文，无需重复交代背景即可启动检索、对比、分析与综合。

**后续方向——端到端自主科研**：方案设计（自主提出创新方案、实验设计、对比策略）→ 工程实现（直接生成可运行代码框架、训练配置、评估脚本，接入计算资源执行）→ 性能调优（分析实验结果、识别瓶颈、自动迭代超参）。最终实现用户定义研究问题、AREX 自主完成探索实验与优化、交付可验证的研究结果。
