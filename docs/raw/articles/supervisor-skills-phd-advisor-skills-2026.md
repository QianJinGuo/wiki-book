把一位博导十年顶会发表/审稿经验蒸馏成 11 个可执行 AI Skill + 一套 handbook 理论课程的「AI 副导师」——纯提示/知识资产，无 agent 引擎。已作为豆包·办公模式「科研评估」与「学术创作」核心技能部署。核心机制（提炼自 /Users/jinguo/phd/Supervisor-Skills 的 README 与 skills/ 目录）：

- **11 个 skills**：idea-evaluator / deep-research（多对抗视角检索 + 逐条引用核验 + MECE 综合）/ vibe-research-workflow / tech-paper-template（六栏思考模板 + Technique vs New Problem 区分）/ intro-drafter（六段式）/ paper-writer / benchmark-paper-template（五支柱）/ paper-polish / pre-submission-reviewer / figure-designer（三类核心图设计范式）/ drawio-reconstruction。
- **idea-evaluator 的独特维度**：5 维框架（更高/更快/更强/更省/更广）+ 范式转移探测 + fatal-flaws 审计之外，**把研究者本人的能力与每周可用小时数同 idea 生命周期的匹配纳入打分**——评估的不是 idea 的绝对价值而是「这个人现在做不做得动」；输出三档裁决 Strong Accept / Accept with Revisions / Reject and Pivot。
- **证据门控写作**（paper-writer）：每个事实性声明必须溯源到 用户材料 / 核验过的检索 / 领域常识 三源之一，引用过独立核查阶梯，交付零占位符。
- **paper-polish 的两层拆分**：语法/去 AI 腔/措辞分寸可机改；**可能动含义的改动逐条标出请人确认**——把润色拆成可机改/需人断两层。
- pre-submission-reviewer 用 CRITICAL/MAJOR/MINOR 严重度分类 + AI 腔词汇黑名单；handbook 含 Idea 生成 5 维框架、论文质量评价、科研作图（动机图/总览图/实验图）、Vibe Research、顶会案例剖析。
