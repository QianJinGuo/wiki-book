# 蚂蚁：专家准则驱动的自适应后训练框架（APTER）

> 来源：小红书论文解读笔记（2026-08-24），解读 Ant Group《APTER: Adaptive Post-Training with Expert-Grounded Rubrics》（arXiv:2608.14212v1）。APTER 通过基于专家准则的细粒度评估 + 自适应修复（Ada-IFT）机制，解决专业领域大模型后训练中「评分标准缺乏结构化领域知识、难以诊断持续性能力缺陷」的问题，显著提升数学推理与医疗问答表现。

## 三句话总结

1. **研究问题**：专业领域大模型后训练中，现有评分标准缺乏结构化领域知识、难以诊断持续性能力缺陷。APTER 提出基于专家准则的细粒度评估 + 自适应修复框架，在数学推理和医疗问答上显著提升。
2. **核心机制**：①构建基于专家准则的评分标准——领域专家建立分层能力准则框架，针对每个查询路由相关准则并实例化为可执行细粒度评分项，保留准则 ID 支持跨样本诊断、无需参考答案；②自适应后训练——利用评分结果同时作为优化信号和诊断信号，除了常规基于评分的 RL，核心创新是 **Ada-IFT**（聚合低分项识别持续性能力短板，动态触发针对性监督微调修复）；③多角色生成与专家校准——分析师/整合者/审计者/优化器多角色 LLM 协作生成评分标准 + 专家在环校准，区分模型错误/评判错误/标准缺陷。
3. **关键结果**：Qwen 系列三个代际模型上，APTER 数学推理平均 +6.13 到 +15.86 分、医疗问答 +5.19 到 +8.04 分，AIME 等高难度竞赛题增益明显；细粒度奖励优于整体偏好（消融显示查询级细粒度评分比二元结果验证/通用粗略准则更能指导优化，开放式医疗任务优势显著）；Ada-IFT 能准确识别逻辑一致性、约束处理等特定能力的持续失败并显著降低失败率面积；专家 grounding 至关重要（基于共享专家准则框架路由生成的评分标准优于无框架生成的独立评分标准）。

## 主要内容

- **专家准则评分标准**：由领域专家建立分层能力准则框架，针对每个查询路由相关准则并实例化为可执行的细粒度评分项，保留准则 ID 以支持跨样本诊断，无需参考答案。
- **Ada-IFT 自适应修复**：利用评分结果作为优化信号 + 诊断信号。除常规基于评分的强化学习外，聚合低分项识别持续性能力短板，动态触发针对性的监督微调（SFT）进行修复。
- **多角色生成 + 专家校准**：分析师、整合者、审计者、优化器多角色 LLM 协作生成评分标准，引入专家在环校准流程，区分模型错误、评判错误及标准缺陷，持续优化评估体系。
- **量化结果**：Qwen 三代模型上数学推理平均 +6.13 至 +15.86 分，医疗问答 +5.19 至 +8.04 分，AIME 等高难度竞赛题增益明显；消融：细粒度奖励优于二元结果验证/通用粗略准则，特别是开放-ended 医疗任务；Ada-IFT 识别逻辑一致性/约束处理等特定能力持续失败并显著降低失败率面积；专家 grounding 比无框架独立评分标准更优。
