# AI 创新实践｜「架构师 Agent」系统化落地

> 来源：阿里技术（刘瑞洲）| 2026-08-27 入库 | v=8 c=9 v×c=72 NEW Entity

## 背景与问题
业界 AI 仍无法很好理解"复杂技术系统"，"架构师"仍只能由人担任。单个技术系统内部 AI 逻辑理解和推理已有较好落地，但"跨复杂业务系统的架构理解与设计"没有系统性解决方案——这是迈向 7×24 小时 Agentic Coding 的必经之路。目标：让大型存量分布式系统成为 AI 可理解、可推理、可验证的工程系统，让 AI Agent 真正变成「架构师」。

### 核心痛点：局部正确、整体错误
大型复杂系统里，AI 写代码未必慢，真正慢的是不知道该从哪里开始、哪些地方绝不能动。这是系统理解问题而非模型能力问题——代码生成能力已足够强，困难在于**缺失跨系统的架构上下文**：一个字段为什么不能删除、历史分支为什么必须保留、MQ 消息为什么只能新增字段不能改语义、接口为什么不能在网关层校验。这些信息散落在历史方案/事故复盘/配置平台/同事经验/未记录的约定中。AI 没有这些事实只能依据局部代码推断 → 最常犯"局部正确、整体错误"（逻辑写在错误服务/加同步调用消耗超时预算/删兼容逻辑破坏老客户端）。

### 白纸 vs 旧城
新系统（白纸）边界可新建、接口可新定、历史包袱少，AI 容易；存量系统（运行多年的城市）至少有四类知识同时影响方案设计：代码（部分实现事实）、文档（部分设计意图）、配置（运行时行为）、经验（没写下来的约束）。没有机制把它们组织起来，AI 难以从 PRD 走到完整技术方案。技术方案设计是整个 AI Coding 的核心源头。

## 业界现状
调研最近 2 年实践：业界普遍意识到把自然语言需求直接丢给 Coding Agent 不稳定，出现 Spec、Harness 等方法论。但这些偏单个微服务系统内部实践，对跨复杂多系统的工业实践未给出理想细节设计。本文向前一步：让 AI 完成"复杂系统理解"，像人类架构师一样跨多系统/多终端做技术方案设计、推理。

## 落地抓手
从架构师核心职能之一——技术方案设计开始。设计思路主要抓手：需求质量、分层知识库（全面性/准确性/渐进式披露）、LLM 基模（推理能力）、技术方案产出规范。

## 知识库建设（承接上一篇《分解一座冰山》）
**首先"对齐领域"：结构化设计**。基模能力越强，越要把原始输入做精确（原始输入越精确，结论越精确高效）。类似带新实习生：给强结构化的文档层层递进，而非丢文档库自己检索。人类架构师有 DDD 等方法论，架构应天然有领域边界、面向领域强结构化。

**反直觉设计：为什么不首推 RAG**。RAG 检索解决的是"从资料中找出可能相关内容"，不天然解决"AI 是否拿到做出完整工程判断所需的知识集合"。问题：①检索结果碎片化、上下文不完整；②低结构/低密度/碎片化资料统一检索，得到的是更容易搜索但依然杂乱的文档仓库；③无法约束 AI 必须理解哪些方面。固定结构提供的是"**知识覆盖约束**"（解决一个业务问题至少要理解哪些方面），RAG 只能"这里有一些可能相关的资料"。

**蒸馏架构师的大脑：业务知识库建设**。开发新 skill 把技术方案设计文档/技术稳定性梳理串讲文档等蒸馏成强结构化业务知识库（也会下载分析交互图）。业务知识库以领域为边界，至少五类内容：元语、场景、领域原则、实践等。固定结构给 AI 确定阅读路径（先读元语避免概念混淆→再读场景→一致性/兼容/降级问题回领域原则→历史原因查实践）。

**知识正确性需要维护机制**：服务知识库与 Git Push/PR/版本发布联动，Hook/CI 按 Diff 识别受影响 API/对象/数据库/消息/配置/测试知识，生成待更新候选并校验。但不过度自动化：对 API 契约/数据库语义/MQ Schema/状态机/历史兼容/安全策略等高风险知识，自动化负责发现变化/生成候选/阻止遗漏，人负责确认语义。业务知识库同样需要人工沉淀 + 自动化校验两种互补机制。

**service-knowledge 答疑**：是否和代码放同一 git repo？如何保证和代码一致性？与 LLM wiki(markdown) 差异？"代码即事实"是否还有存在必要？（基于文中及上一篇的回答框架）

**渐进式披露：强结构化知识路径**。分层（四层）：业务层（为什么改/业务落在哪/元语对应哪些系统或API，business-knowledge+蒸馏）、架构层（涉及哪些系统/影响谁，aitom/服务图谱/接口依赖）、系统层、实现层。每层迭代频率递增，让下一步由前一步结论触发。

## 落地价值
让 AI 对人的依赖进一步降低，更快迈向 7×24 小时 Agentic Coding 和交付。把「存量大型分布式系统」从只存在于少数人脑中，变成 AI 可全方位理解、参与方案设计/研发执行/线上排查的工程系统。
