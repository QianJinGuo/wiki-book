# 开放K3权重、抢招全球大使，Kimi这次想干什么？

编辑｜杨文

刚刚，月之暗面正式启动 Kimi 全球大使计划，面向全球招募一批先行者。

而就在昨晚，月之暗面刚把 Kimi K3 的技术底牌摊开了。

模型权重、技术报告，以及支撑模型训练的 MoonEP、FlashKDA 和 AgentEnv 三项关键 Infra 技术，一次性向全球开放  。

月之暗面究竟要打一副怎样的明牌？

* Kimi K3 模型权重：https://huggingface.co/moonshotai

* Kimi K3 技术报告：https://github.com/MoonshotAI/Kimi-K3

* MoonEP GitHub 仓库：https://github.com/moonshotAI/moonep

* FlashKDA GitHub 仓库：https://github.com/MoonshotAI/FlashKDA/

* AgentENV GitHub 仓库：https://github.com/kvcache-ai/AgentEnv

Kimi K3 是一个拥有 2.8 万亿参数的混合专家模型，具备原生视觉理解能力，支持 1M 超长上下文。参数规模约为 Kimi K2.5 的 3 倍。

借助 Kimi Delta Attention、Attention Residuals 和 MoonEP 等技术，Kimi K3 规模化效率提升了 2.5 倍。

现在，任何人都可以下载和部署 K3，用于内部研发或嵌入终端产品。

同步公布的技术报告，进一步披露了 KDA + AttnRes、Stable LatentMoE、MoonViT-V2，以及百万 token 上下文强化学习等技术细节。

月之暗面还进一步开放了支撑 K3 训练的关键基础设施。

MoonEP 面向超大规模细粒度 MoE 的专家并行通信；FlashKDA 是 Kimi Delta Attention 的高性能算子，在英伟达 H20 上，prefill 速度较 flash-linear-attention 基线提升 1.72 至 2.22 倍；AgentEnv 为大规模 Agent 后训练提供高保真、强隔离的沙箱环境，支持快照、恢复和分叉。

可以说，  Kimi K3 几乎开放了训练链路中最关键的几层  。

这场开放的时间点也很微妙，围绕开源与监管，美国科技界和政策界刚刚经历了一轮罕见交锋。

上周五，英伟达创始人黄仁勋发出了他人生中的第一条推特，分享的是一封英伟达联署的公开信《开放权重与美国 AI 领导力》。

信中写道：世界需要前沿闭源模型，也需要前沿开源模型。

同时联署这封信的，还有微软、Meta、Hugging Face、Mistral、YC 等 20 多家科技巨头、创业公司和投资机构。

此举甚至迫使 OpenAI 公开表态，加入支持者行列。

公开信没有直接点名 Kimi K3，发布时间却恰好落在一场由 K3 引发的政策争论之后。

据 Axios 报道，特朗普政府内部重新讨论是否加强对中国开源模型的管控，美国财政部等部门也在研究可能的限制措施。

消息一出，近 200 家硅谷初创公司迅速组成「小科技联盟」，向政府发出警告：封杀廉价开源模型，就是逼着初创公司向 OpenAI 和 Anthropic 缴高额 API 费，这将直接摧毁大量资金有限的美国创业公司。

黄仁勋在接受采访时也表达类似态度，美国企业「当然应该」被允许使用中国模型，并称这些中国模型「非常优秀」。在他看来，低价、开放的模型会扩大 AI 使用量，最终带来更多芯片和数据中心需求。

这起争论侧面说明，  K3 已经很难被当作普通的中国开放模型看待  。

作为全球首个开放权重的 3 万亿参数级模型  ，Kimi K3 发布不到一周，便接连刷新各大榜单。

在权威大模型竞技场 Arena.ai 的前端代码排名中，Kimi K3 位列第一；在 Artificial Analysis 智能指数中，它排在第三。

K3 第三方评测发布后，马斯克在底下留言「Impressive」。

随后，马斯克介绍 xAI 正在训练的 2 万亿参数模型时表示，新模型「可能超过 Kimi」。Kimi 由此成为 xAI 下一代模型需要参照的对象。

《Interconnects》创办人 Nathan Lambert 则认为，Kimi K3 已经属于真正的前沿模型，把开源与闭源之间的能力差距，从原来普遍讨论的 6 至 9 个月，压缩到了 3 至 5 个月。

华尔街分析师用「本垒打」来形容 K3，认为中国 AI 的创新速度越来越难被全球市场忽视。

企业端的测试也已经开始。据《The Information》报道，微软正在评估月之暗面 Kimi K3，测试其是否能够用于 Copilot，并计划将该模型接入 Azure。

外部企业还在评估，Kimi 自己的 GPU 已经先感受到压力。Kimi K3 上线后的 48 小时内，用户请求量大幅超出预期，Kimi 随后暂停新增会员订阅，会员页面全部显示售罄。

模型权重已经向全球开放，Kimi 的下一步，是进入更多社区和真实工作流。这也把问题引向了刚刚启动的全球大使计划：Kimi 究竟想找什么样的人？

申请链接：https://www.kimi.com/zh-cn/lp/kimi-ambassador

Kimi 想找什么人？

Kimi 全球大使计划想要寻找的，是已经深度使用 Kimi、理解 AI 产品，并愿意主动分享经验的人。

这些人可能来自开发者社区、校园、创业公司，也可能是写作者、研究者、产品经理、内容创作者、社区组织者，或者已经把 Kimi 放进日常工作流的用户。

全球大使并非隐藏在后台的产品测试者，也并非机械转发官方内容的传播账号。  他们要做的，是把具体场景、使用方法和产品边界讲清楚  ，可以在城市、校园、公司或开发者社区里组织 Workshop、Meetup、Demo Night、技术沙龙、黑客松、产品演示会或 Office Hour，让更多人理解 Kimi 能解决什么问题。

Kimi 看重的不是单纯的粉丝数量，更重要的是真实使用、主动性、创造力、可信度、组织能力和反馈质量。一个合格的全球社区大使，要能把 AI 产品讲给更多人听，也要能把真实世界的问题带回产品团队。

为了支持这些行动，  Kimi 给出五类资源  。

正式发布前，大使就能优先体验前沿模型与实验性新功能，反馈直接进入迭代流程，在产品定型之前就参与并影响它的最终走向。

日常使用和社区活动上，大使可获得 Kimi API 额度与项目配套支持等专属权益。

大使还能把产品建议直接带给 Kimi 一线团队，定期交流、共创，获得针对具体场景的定制化指导，也第一时间了解产品路线背后的思考。

社区贡献与原创成果，有机会通过官方渠道获得公开曝光与权威认可。

此外，全球大使网络本身也是一种资产，链接全球优秀 AI 开发者、研究者与创作者，加速个人职业发展。

为什么大模型公司都在找社区大使？

过去一年，海外 AI 公司也在加速建设自己的社区大使网络。

Anthropic 推出了 Claude Community Ambassadors，鼓励大使在所在城市组织 meetup、workshop 和黑客马拉松，把 Claude 用户和开发者聚在一起，同时把社区反馈带回产品团队。

OpenAI 也有 Codex Ambassadors，面向社区组织者、开源维护者、学生领袖和深度用户，帮助 Codex 扩散真实工作流，让更多人理解它怎么进入开发过程。

这类项目的出现，  和大模型产品的使用方式变化有关  。

早期大模型产品的使用路径相对简单。用户打开网页、输入问题，就可以获得回答。产品教育主要围绕提示词、回答质量和基础功能展开。

到了 Agent 阶段，产品开始进入更复杂的工作流。它要读文件、调用工具、操作浏览器、跑代码、生成网页、写脚本、处理表格，甚至拆解长任务。官方文档已无法覆盖所有使用场景。真实用户在具体工作流中积累的经验，成为官方渠道之外的重要信息来源。

对行业来说，社区大使项目的增多，也说明  AI 产品竞争正在进入新阶段  。

第一阶段，竞争主要集中在模型能力。参数规模、上下文长度、推理能力、生成质量和基准成绩，是公司对外展示的核心指标。

第二阶段，竞争开始转向产品和工作流。谁能把模型能力放进真实任务，谁就更接近用户的日常工作。

现在，社区正在成为新的变量。AI 产品的扩散，不再只依赖发布会、广告和应用商店。真实用户的工作流、案例、教程、活动和反馈，正在参与产品迭代。

Kimi 正在扩大产品触点，把模型能力放进更多使用场景。然而，场景越分散，产品团队越难只依靠内部测试理解真实需求。Kimi 全球大使计划对应的，正是产品边界变宽之后的反馈需求。它既承担社区扩散，也承担使用经验的收集、筛选和回传。

技术之外，是人

对大模型公司来说，社区不只是增长渠道，也是一种  产品反馈机制  。

大模型没有固定的使用边界，不同人会在自己的工作流中重新定义它，这就导致大模型公司普遍面临信息不对称的问题：模型能力的边界、最佳实践和真实痛点，并不完全来自实验室测试，也无法完全由榜单衡量，它们往往沉淀在一线用户的具体工作流里。

社区的作用，是把这些分散经验组织起来  ，让有效方法被传播，让产品团队获得更接近真实场景的反馈。

技术发展的意义，也不只在于能力指标持续提升，更重要的是，它如何进入人的生活，如何改变人的工作方式，这些最终都需要在人与人的交流中被验证。

从这个角度看，Kimi 招募全球社区大使，  本质上是在建设一套连接用户、场景和产品的反馈网络  。

接下来就看 Kimi 首批全球社区大使，能否把 Kimi 带进更多真实工作流，并把分散的用户经验沉淀为可持续的产品资产。
