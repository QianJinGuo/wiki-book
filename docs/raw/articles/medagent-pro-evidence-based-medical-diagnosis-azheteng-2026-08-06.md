# MedAgent-Pro: Towards Evidence-Based Multi-Modal Medical Diagnosis via Reasoning Agentic Workflow

> ICLR 2026 论文解读。作者：Ziyue Wang, Junde Wu, Linghan Cai, Chang Han Low, Xihong Yang, Qiaxuan Li, Yueming Jin。单位：新加坡国立大学、牛津大学、哈尔滨工业大学（深圳）、国防科技大学、浙江大学医学院附属第二医院。arXiv:2503.18968。

## 一句话概述

MedAgent-Pro 不再让 VLM 凭内部知识直接"看图给答案"，而是把医疗诊断拆成两层：先在**疾病层**根据医学指南生成标准化诊断计划，再在**患者层**调用分割、grounding 和编程等工具，逐步产生可量化证据，并对每一步结果做可靠性反思。

核心转变：把医疗 AI 的输出从"一次性结论"升级为"指南支持的计划 + 工具支持的证据 + 可追溯的推理链"。

## 研究背景：真实诊断不是一道 VQA 题

传统医疗 VQA 是"给图+问题→答案"。真实临床诊断需联合影像、病历、人口学信息与检验指标，遵循疾病对应的标准化流程。以青光眼为例：需定位视盘视杯、计算垂直杯盘比（vCDR）、分析神经网膜边缘形态、盘沿出血和盘周萎缩，才能综合判断风险——任何中间环节不可靠都会污染后续结论。

现有方法三个结构性缺口：
1. **缺少可量化证据**：通用 VLM 擅长语言流畅的定性解释，不擅长分割、测量和几何计算
2. **工具调用静态**：早期医疗智能体按固定顺序调工具，不同疾病需要不同指标，"拥有工具"≠"会用工具"
3. **结论缺少证据追溯**：临床安全关心中间结果是否有生理学可能性、输入图像是否支持操作、哪些指标真正进入决策

## 核心方法：疾病层计划 + 患者层推理

### 疾病层：两阶段 RAG 把指南转成可执行计划

- 用 MedlinePlus 构建知识库：1,000+ 疾病、4,000+ 篇 NIH/NLM 审核指南文章
- **两阶段检索**：①按器官/疾病元数据摘要粗筛 → ②候选全文切 300-token 片段用 PubMedBERT 编码取 top-5 → VLM 汇总生成过程性指南并提取疾病特异临床指标
- VLM 生成疾病特定诊断计划（JSON 格式），每一步含操作、固定行为的 Python 函数、期望输入/输出字段——"医学指南"被转化成一串可执行节点
- **工程价值**：疾病层规划只生成一次，可多位患者复用，指南检索和流程生成不必每个病例重复

### 患者层第一步：数据初始化长期记忆

标准计划未必适用每位患者（数据缺失）。检查计划中每步输入条件，仅保留当前数据能支持的步骤存入长期记忆——**避免为不存在的输入生成虚构结果**。

### 患者层第二步：工具化 Action 生成定量证据

- 定性分析：VLM 直接根据图像与指南描述异常
- 定量分析：调用专业工具——分割模型提取视杯视盘 → 编程工具根据 mask 计算 vCDR；心脏影像通过心室/心肌分割计算 LVEF、LVEDD、LVMI
- 工具集：Medical SAM-Adapter、MedSAM、Cellpose、Maira-2 + GitHub Copilot 编程/解析工具（仅青光眼/心脏病有 ground-truth mask 做了训练，其余 zero-shot）

### 患者层第三步：Evidence-based Reflection 阻断不可靠分支

每步 Action 后由 zero-shot VLM 评估器做状态判断：
- **Continue**：结果可靠但非最终指标 → 作为下一步输入
- **Terminate**：结果不可靠 → 停止该分支，避免错误传播
- **Complete**：已得到可用临床指标 → 收入最终证据集

反思检查四类问题：输入图像模糊/遮挡/缺失目标区域；分割 mask 尺寸形状解剖关系合理性；数值是否在生理学范围（vCDR < 1，视杯在视盘内）；定性语句是否有明确视觉/文本证据。最大推理轮数 10，超限分支终止并从决策排除。

### 最后决策：指南约束的风险加权

收集所有 Complete 指标 → VLM 按医学指南分配临床风险权重 → 加权风险分数超阈值给阳性诊断。"先结构化、再融合"——flat fusion 模型易过度关注局部线索，结构化加权随指标数量增加更稳定。

## 数据集与设置

- **REFUGE2**（青光眼）：1,200 张 2D RGB 眼底图（2124×2056），含分割 mask 和分类标签
- **MITEA**（心脏病）：143 人 536 个 3D 超声心动图，简化二分类
- **MIMIC-CXR**：100 人 442 例，每例最多 12 种胸部异常并行识别
- **NEJM 现实案例**：992 个多选题式病例，10+ 解剖区域/影像模态/50+ 疾病

## 实验结果

### 主结果

| 任务 | MedAgent-Pro | GPT-4o | 提升 |
|------|-------------|--------|------|
| 青光眼 bAcc/F1 | 90.4/76.4 | 56.4/21.1 | +34.0/+55.3 |
| 心脏病 bAcc/F1 | 77.8/72.3 | 56.8/28.1 | +21.0/+44.2 |
| NEJM 准确率 | 81.7% | (MDAgent 73.8%) | +7.9 |

- REFUGE2 AUC 95.1% vs 挑战赛最佳 88.3%（+6.8）；vs 眼科 VLM VisionUnite bAcc/F1 +4.6/+3.3
- MIMIC 12 任务平均 bAcc 72.0% vs GPT-4o 58.3%（+13.7），仍高于 CheXagent 69.1% / Maira 64.1%；但非每项最佳（CheXagent Lung Lesion 81.8%/Pneumothorax 84.2% 领先）——强项是跨任务平均稳定性

### 消融

- 仅 GPT-4o 青光眼 56.4/21.1 → +计划 75.9/36.5 → +工具 88.5/71.0 → +反思 90.4/76.4（最大 F1 跃升来自 Tool-based Action：+34.5 青光眼/+20.7 心脏病；反思 +5.4/+5.7，作用=管理已有能力输出质量）
- **不是"把工具都给 VLM"就行**：工具直给基线 74.4/52.3 仍低于 90.4/76.4——工具是能力上限，计划决定能力能否组成诊断链
- 分割 IoU 与诊断性能正相关：智能体不消除底层视觉误差，只纳入可检查、可终止的流程
- RAG 换实现（FAISS vs LangChain）差异很小；top-k 非单调，k=5 心脏病最优，k=1 青光眼 F1 反而最高
- 无工具 NEJM 案例仍 84.0% > MDAgent 77.5%——规划与检索本身就有贡献

### 成本与临床评估

- 单例平均推理 44.6 秒（A6000）：慢于 GPT-4o 21.2s/MMedAgent 32s，快于 MedAgents 143s/MDAgent 272s；计划+代码执行开销 <1s，主要时间在骨干 VLM；疾病层计划可复用摊薄成本
- 两位持证临床医生（眼科/胸外科）五维盲评（相关性/全面性/可靠性/连贯性/清晰度）：MedAgent-Pro 全维度领先且跨病例波动小
- 可解释性来自中间产物：检索到的指南/JSON 计划/分割 mask/grounding 区域/计算指标/分支状态，错误可归因到具体环节

## 不足与未来

- 高度依赖外部工具覆盖与质量；反思仍由 VLM 实现（继承幻觉/过度自信）；定性分析幻觉风险未消失；MITEA 简化二分类、MIMIC 仅 100 人 442 例；专家评估规模有限（各 1 人）；附录表 13 文字与数值不一致（ACC/AHA 实际小幅下降）；临床部署缺概率校准/失败拒答/人机协作/审计证据
- 未来：独立验证器（mask 解剖合理性/数值生理范围/图文一致性多源交叉验证）、工具能力与失效模式注册表、本地化可版本化指南知识库、纵向多模态记录、前瞻性多中心研究

**延伸思考**：MedAgent-Pro 最有启发性的地方是把"模型知道什么"、"工具能测量什么"和"哪些结果有资格进入决策"明确分开——计划、测量、验证和决策分别留下可审查的证据。
