# GeoRA: 为RLVR设计的LoRA——ACL 2026杰出论文解析

> 来源：美团技术团队（美团履约平台）| 2026-08-27 入库 | v=8 c=9 v×c=72 NEW Entity

美团履约技术团队《GeoRA: Geometry-Aware Low-Rank Adaptation for RLVR》入选 ACL 2026 杰出论文奖（全球仅 18 篇，圣地亚哥揭晓）。

## 背景、洞察和目标
RLVR（可验证奖励强化学习）已成为提升大模型推理能力的关键范式，但训练开销高，自然想用 LoRA 类参数高效微调（PEFT）来做 RLVR。但 LoRA 及其变体几乎都在 SFT 场景建立验证，而机制研究表明 **RLVR 与 SFT 的优化几何存在本质差异**：
- SFT 通过改写权重主方向显式注入新信息；
- RLVR 更像受约束的优化，靠奖励诱导采样偏置放大推理行为，**有效更新分散在稀疏子空间、倾向于避开预训练权重主方向**；且对更新稳定性敏感，激进或落在主方向的更新易引发谱漂移、探索多样性坍塌甚至训练崩溃。

### 现有 PEFT 的错位
- **几何错位**：LoRA 用高斯/全零初始化（与预训练权重无关）；PiSSA 对原始权重 SVD、把预算全给主奇异方向；MiLoRA 取尾部奇异方向。这些谱先验主要在 SFT 设计验证，未考虑 RLVR 更新规律。PiSSA 把更新强推主成分的强归纳偏置恰与 RLVR 偏好子空间冲突（实验中更易崩溃）。
- **工程错位**：直接对 RLVR 偏好的稀疏子空间做稀疏微调，更新模式契合但 GPU 对非结构化稀疏不高效——实验里稀疏微调把训练参数降 68.0%，训练耗时反而 +10.8%。

### GeoRA 目标
同时解决两个错位：定位契合 RLVR 的稀疏子空间，用**低秩稠密**方式去训练它。

## 方法：GeoRA 的构造（三步骤）
1. **构造几何子空间**：基于谱先验 M_Spec 和欧氏先验 M_Euc 从预训练权重筛出更稳定、可塑的参数区域，两者共用稀疏率 ρ，最终取并集 W_Geo = W ⊙ (M_Spec ∪ M_Euc)。
   - 谱先验 M_Spec（强调稳定性）：对 W 做秩 r 低秩近似得到 Ŵ_r，选出其中幅值最小的 ρ 比例位置（主成分高幅值=高曲率，改动易破坏预训练结构；限制在低幅值区改善谱稳定性）。
   - 欧氏先验 M_Euc（强调可塑性）：直接在原始 W 上选幅值最小的 ρ 比例位置（接近零的参数在预训练中"用得少"、可调整空间大）。
   - 两掩码互补：Qwen3-8B 上 ρ=0.2 各选中 20% 参数但交集仅 4.55%、Jaccard 相似度 0.128；消融证实去掉任何一个先验都性能下降。
2. **低秩近似构造适配器**：对 W_Geo 做 SVD（W_Geo = U_Geo Σ_Geo V_Geoᵀ），取前 r 个奇异分量初始化 A_Geo、B_Geo（B_Geo A_Geo 是 W_Geo 的最优秩-r 近似，Eckart–Young 定理保证 Frobenius 最优）。**关键区别：GeoRA 取的是 W_Geo 的 top-r，而非原始权重 W 的 top-r**。
   - 四方法区别一句话：LoRA 不看权重，PiSSA 看主方向，MiLoRA 看尾方向，**GeoRA 先换一个更合适的适配对象，再在其中取主方向**。
3. **建立残差锚点**：按 LoRA 缩放约定计算残差 W_res = W − (α/r)·B_Geo A_Geo，前向 h = W_res x + (α/r)·B_Geo A_Geo x。两个性质：
   - 初始化时函数不变（两项之和恰等于 Wx），避免冷启动策略抖动——对 RLVR 重要，初期输出扰动会污染 rollout 采样分布；
   - 结构约束：优化器只能在 A_Geo/B_Geo 参数化的流形上更新，W_res 作稳定锚点防预训练表示被破坏。

预处理只执行一次（一次性），训练阶段计算图与标准 LoRA 完全一致。

## 实验验证
主实验 DeepMath-103K 用 GRPO 对 Qwen3-8B 和 Llama-3.1-8B 做数学 RLVR，对比 LoRA/PiSSA/MiLoRA/稀疏微调(SparseFT)/全参微调(FullFT)，4B 与 1.5B 上用 GSM8K 验证规模。

- **数学推理与 OOD**：ID 基准 GeoRA 两个骨干都最强，竞赛难度领先一致（Qwen3-8B AIME24 23.75%，甚至略高于全参微调）。OOD 更关键：全参在 IFEval/TruthfulQA 明显回退，GeoRA 基本无损，HumanEval 反而 76.83→82.93 → 几何对齐的子空间更新提升目标域同时减少遗忘。
- **医学/代码**：两领域结论一致，GeoRA 稳定优于低秩基线、与全参相当。
- **收敛效率与稳定性**：全程领先、达到高位性能更早；超参鲁棒（学习率宽区间维持高奖励，其他方法大学习率下滑）。
- **计算效率**：vs 全参，可训练参数 -99.5%、单步耗时 -19.9%、显存 -28.5%；对照 SparseFT（-68% 参数但 +10.8% 耗时）说明 GeoRA 把几何先验落成稠密低秩计算，参数效率真正转化为速度与显存收益。
- **低秩结构分析**：三组奇异值谱分析证明"低秩是 RLVR 的内在属性"——稀疏本身不带来低秩（随机噪声矩阵各向同性）；W_Geo 谱形类似预训练权重（主能量集中前导分量，可压缩）；全参 RLVR 实际更新 ΔW 也呈重尾谱。这解释 GeoRA 只训练 0.5% 参数就与全参相当。

## 业务应用：AI 骑手招聘 Agentic RL
场景：AI 主动触达跟进候选人，多轮沟通识别意愿/顾虑/决策卡点，推进面试入职（约面/入职/ROI 可验证，适合 RLVR）。训练需求组合：基模大（需大尺寸基模+长上下文）、增量能力规模不大（垂直域知识规模远小于基模，低秩容量足够承载）——正是 RLVR 低秩高效训练的用武之地。业务体感最早怀疑"为 SFT 设计的低秩先验未必适合 RLVR"：LoRA/PiSSA/MiLoRA 效果差异明显、学习率调大训练不稳甚至崩。

落地结果：**效果与全参训练相当、相比 LoRA 提升约 12%；效率与 LoRA 相当、显存相比全参降低 54%**（配合 QLoRA 可进一步降）。

落地经验：
- **随机 SVD 初始化**：一次性预处理，只需前 r 个奇异分量，可用 Randomized SVD 加速（随机投影压到小空间再分解），72B 模型 <1 分钟。
- **省略参考模型存储**：RLVR 需参考策略算 KL，常规做法存一份完整权重；利用函数不变性质（原始权重=残差权重+初始适配器），只要在 actor 内多留一份冻结的初始适配器（低秩、开销小），就能现算准确参考策略。

## 总结（三大贡献）
1. 揭示 RLVR 更新结构：更新子空间稀疏但各向异性可压缩，是低秩适配成立的前提。
2. 定位+压缩适配方法：谱先验与欧氏先验定位 RLVR 偏好更新区域 + 截断 SVD 压缩为低秩适配器 + 冻结残差锚点，避免几何错位与稀疏计算效率瓶颈。
3. 广泛实验：1.5B-32B 模型、数学/医学/代码 RLVR 稳定优于基线，OOD 遗忘更少，兼具速度与显存优势；业务 Agentic RL 以更低成本取得更好效果。

GeoRA 是首个面向 RLVR 优化几何设计的低秩训练方法。
