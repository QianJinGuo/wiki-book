# 李飞飞团队重构具身智能接口：「视觉轨迹」成为世界模型新语言

> 来源：PaperWeekly | 2026-08-28 入库 | v=8 c=8 v×c=64 NEW Entity


原创 让你更懂AI的 2026-08-27 20:53 北京

让机器人先预演再行动

## 

动作指令很适合让机器人执行，却未必适合让世界模型预测未来。李飞飞、吴佳俊团队尝试用视觉轨迹补上这层接口。

**李飞飞、吴佳俊团队，最近又在机器人世界模型上推进了一步。**

这项工作从策略模型和世界模型之间的信息接口切入。现有这类方法通常把机器人动作作为世界模型的条件信号，但动作依赖具体机器人本体，也很难直接描述图像空间中任务相关点接下来如何运动。

研究团队于是把视觉轨迹（Visual Tracks）放到了控制与预测之间，让策略模型同时给出动作和对应的视觉轨迹，再由世界模型根据轨迹预演未来。

基于这套思路，他们提出了 **TrAct ，用视觉轨迹串起策略生成、未来预测和动作选择。**

论文标题：

TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks

论文地址：

<https://arxiv.org/pdf/2608.24101>

一旦任务开始变难，视觉轨迹的优势就出来了。

以 π0.5 为基线，TrAct 在 LIBERO-INTEGRAL 上将平均成功率从 27% 提升到 55%；真实 Franka 面对未见任务和背景变化时，也从 49% 提升到 76%。而且，**世界模型对未来的预测也更准了 。**

动作为什么不是理想接口？

机器人动作通常是低维、与具体本体绑定的控制指令。Franka 和 UR5 即便完成相似操作，也可能需要不同的控制指令。

同一动作最终产生什么视觉结果，又取决于场景几何、物体状态和接触动态。世界模型需要从这些稀疏、与本体相关的指令中推断稠密的视觉未来。

论文引用的已有研究甚至发现，动作条件视频模型可能忽略错误动作，更多依赖视觉先验生成看似合理的结果。

视觉轨迹则直接描述任务相关点在图像空间里如何移动，为未来预测提供更明确的空间约束。

〓TrAct 的整体思路与视觉轨迹接口

视觉轨迹如何连接控制与预测？

TrAct 由 VLAT、TWM 和 VLAC 三部分组成。

VLAT 建立在 π0.5 上，根据当前观测和语言指令，同时生成多组动作与视觉轨迹。两者联合预测、成对输出，轨迹并不是由动作再转换得到。

视觉轨迹描述的是任务相关点随时间在图像空间中的二维运动。模型会跟踪夹爪上的 7 个关键点，腕部视角还加入 5×5 个均匀采样的场景点，为场景和相机运动提供参照。

随后，TWM 根据当前观测和这些轨迹生成未来视频。它以 Stable Video Diffusion 为骨干，通过 ControlNet 将视觉轨迹编码为空间控制条件。

作为直接对照，团队还训练了动作条件世界模型 AWM。两种世界模型使用相同的预训练数据和下游微调数据。

候选视频生成后，VLAC 根据任务指令逐一打分，系统再执行最高分结果对应的动作。每个决策步，仿真采样 20 组候选，真机采样 16 组。

〓TrAct 的策略生成、未来预测与结果筛选流程

此前已经有工作把二维点轨迹、光流用于策略表示，也有研究用视觉运动来条件化世界模型。**TrAct 的区别，是进一步让这种中间表示进入基于视觉未来的任务评估闭环。**

世界模型想得更准，机器人才能选得更准

动作条件世界模型容易出现夹爪姿态错误、物体消失、跨视角位置不一致等问题。改用视觉轨迹后，未来视频的空间位置更准确，运动也更连贯。

〓两类世界模型的未来视频定性对比

在真实与仿真、外部视角（agent view）与腕部视角（wrist view）下，TWM 在五项视频指标上全部优于 AWM。

以仿真外部视角为例，PSNR 从 15.12 提升到 24.51，LPIPS 从 0.438 降到 0.106，FVD 从 129 降到 38。

〓轨迹条件与动作条件世界模型的视频预测质量

LIBERO-INTEGRAL 中，π0.5 的平均成功率为 27%；联合预测动作和视觉轨迹后，VLAT 升至 44%；加入动作条件世界模型筛选达到 49%；采用轨迹条件世界模型后，TrAct 进一步达到 55%。

VLAT+AWM 与 TrAct 沿用同一套 VLAT 候选生成和 VLAC 筛选流程，主要区别在世界模型的条件信号：前者使用动作，后者使用视觉轨迹。

在三个独立随机种子下重新评估，TrAct 的平均成功率为 54.7%，VLAT+AWM 为 49.0%，两者 95% 置信区间没有重叠。

〓轨迹条件与动作条件世界模型的视频预测质量

 _LIBERO-INTEGRAL 在不同分布偏移与跨本体设置下的结果。_

从未见背景到 UR5，泛化才是关键

标准 LIBERO 已经接近饱和，π0.5 和 TrAct 的平均成功率分别为 96.8% 和 98.3%。

因此团队进一步构造 LIBERO-INTEGRAL，加入物体替换、物体位置、任务设定、相机视角和机器人初始状态等变化，以及 Franka→UR5 的跨本体测试。

其中跨本体一项，π0.5 只有 17%，TrAct 达到 50%。

真实机器人实验中，团队在 Franka 上收集了 400 条演示，覆盖 4 个训练任务，并用这些数据微调模型。

随后测试 5 个训练中没出现过的操作任务，每个任务都分别在训练背景和一个视觉差异明显的未见背景下测试。

〓真实机器人任务中的执行序列与轨迹预测

最终 π0.5、VLAT+AWM 和 TrAct 的平均成功率分别为 49%、66% 和 76%。

〓真实机器人分布外任务及不同背景下的成功率

未见背景下差距更明显。关柜门任务中，VLAT+AWM 的成功率只有 40%，TrAct 仍达到 70%。绿块入碗和倒意面任务上也有约 20 个百分点优势。

论文认为，轨迹条件直接约束了图像空间中的运动，因此在背景变化下更稳健。

〓训练背景与未见背景下的真实机器人轨迹预测

这种统一轨迹表示还让 DROID 机器人数据和 EgoDex 人类第一视角视频共享同一个轨迹预测目标。

EgoDex 中的人手运动和机器人可执行动作无法用同一套控制参数表示，因此只用来监督视觉轨迹，机器人数据则同时监督轨迹与动作。

扩大预训练数据后，TrAct+ 在**选取的 5 个最困难 UR5 任务** 上，从 32% 进一步提升到 38%。

结语

TrAct 最终执行的仍是机器人动作，真正变化的是策略模型与世界模型之间的信息接口。

在这里，视觉轨迹更像是一种共同语言：一头连着机器人的控制，一头连着世界模型对未来的预测。
