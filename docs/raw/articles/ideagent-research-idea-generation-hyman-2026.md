# 南洋理工开源 IDEAgent：兼顾idea的质量和多样性

南洋理工大学 DeCLaRe Lab 开源 IDEAgent：把科研想法生成做成「质量 + 多样性」联合搜索，用谱系管理、修复与精炼抬高想法质量，在 32 个计算机科学主题上，Yield 比最强基线高 3.89 倍。

论文标题：IDEAgent: Agentic Quality-Diversity Search for Research Idea Generation
论文链接：https://arxiv.org/abs/2607.22375
Github 链接：https://github.com/declare-lab/IDEAgent

## 核心问题

科研想法生成的两难：连续十条「给大模型加检索」的课题，每条写得像样但本质是一条线 → 多样性不足。反过来，十条彼此很远但逻辑漏洞多、机制写不清 → 质量不足。

IDEAgent 将此事写成质量-多样性（Quality-Diversity, QD）搜索。配套指标 **Yield**：固定生成预算下，能留下多少条「够好、又两两够不一样」的想法。

## 系统组件

### 想法演化流程

一条想法走完整体流程：
1. **Ideator**：读背景语料，写出种子想法，或按反馈改写
2. **Stenographer**：把较长提案整理成五项统一摘要（问题、中心机制、新增价值、关键假设、可测预期）
3. **三位评估者**：
   - 质量评估：非显然性、机制清晰度、可行性（0-100）
   - 严谨性小组：同一模型独立打分5次（每次0-9），有争议则进入修复
   - 多样性裁判：对照当前活跃想法和历史想法判重复度
4. **Critic**：把分数与失败证据收成针对性反馈
5. **Controller**：维护四类轻量记忆（活跃档案、修复队列、历史档案、拒绝模式库）

### 候选去向

- 旧路弱化版 → 淘汰
- 同路线竞争 → 替换或丢弃
- 新路线 → 过门可进活跃集；接近阈值给一次修复

## Yield 指标

先按非显然性、严谨性、清晰度阈值筛高质量子集，再在两两多样性约束下，取出满足「彼此都够远」的最大想法集合。集合越大，Yield 越高。

## 实验结果

32 个计算机科学主题，每主题预算 10 条想法，双外部裁判（Claude Sonnet 5 + Claude Opus 4.7）：

- **Yield(NB≥7)**：IDEAgent 1.094，NOVA 0.281，Sequential-Memory 0.188。相对最强基线约 3.89 倍
- **Yield(NB≥6)**：2.312 vs NOVA 的 1.156（约 2 倍）
- **至少 1 条合格想法（NB≥7）**：IDEAgent 27/32，最佳基线 8/32
- **至少 2 条（NB≥7）**：IDEAgent 8/32，基线最多 1/32

修复与精炼效果：全部 320 条谱系中，修复 30 条尝试→28 条合格，精炼 182 条→151 条新版替换。严谨性受益最大（+23.2），清晰度次之（+16.7），非显然性也约 +7。

## 边界

- 评测主路径仍是 LLM 裁判，双模型等权降偏
- 可行性被刻意排除在主门控外
- 修复只有一次，精炼最多两次
- 开源小模型在两端不够用，实验绑在专有模型上
