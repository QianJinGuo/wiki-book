# WWW 2026 | 强化学习重塑GraphRAG，多跳推理F1提升83.81%

原创 让你更懂AI的 2026-08-10 18:09 北京

给RAG装上自主检索能力

检索增强生成（RAG）可以让大语言模型通过外挂知识库博览群书。然而，RAG 遇到需要“拐几个弯”才能回答的复杂问题仍然容易翻车。检索工具擅长匹配相似的信息，却不擅长捕捉解决问题所需要的底层推理逻辑。

来自南开大学、北航、港科大（广州）、华为等机构的研究者提出 GraphRAG-R1，通过创新的“过程约束强化学习"机制，让大模型学会在知识图谱上自主推理、按需检索。

方法在多个复杂推理数据集上取得 SOTA 成绩，F1 分数最高提升 83.81%，并能即插即用地适配各类 RAG 系统，带来平均 20%+ 的稳定性能增益。

该工作已被万维网顶级会议 WWW 2026 接收为 Oral（317 / 3370，录用比前 10%）。

GraphRAG-R1: Graph Retrieval-Augmented Generation with Process-Constrained Reinforcement Learning

大模型的“死穴”：不会拐弯的推理

先来一道热身题：

录制了专辑《Never Too Loud》的乐队成立的那座城市，灰狗巴士从哪里发车？

对人类来说，几步简单的思考和检索就能处理：先查找专辑对应的乐队，再找到乐队成立的城市，再查那座城市的交通信息。

但对大语言模型而言，即便接入了检索增强生成（RAG）技术，传统的图检索方法（GraphRAG）在面对这类多跳推理问题时，依然存在两大硬伤：

  * 检索太“浅”：检索依赖预设的相似度匹配，不会推理检索的底层逻辑和需求，也不懂得按需灵活控制搜索步骤，关键信息就此缺失。

  * 推理太“僵”：固定步数的遍历策略，要么不够用，要么在复杂图谱里"迷路"，推理链越复杂、跨度越大就越容易断裂。 




Question：能不能让模型像人一样，自己判断“什么时候该去查资料”以及“查到什么程度该收手” ？

GraphRAG-R1：用强化学习给模型立“奖惩规矩”

GraphRAG-R1 的核心思路很直接：与其手写死板的检索规则，不如用强化学习（RL） 训练模型，让它自己摸索出最优的检索与推理策略。

但直接套用现成的 RL 方法会面临奖励欺骗（Reward Hacking）风险——模型可能为了拿高分而钻空子，比如胡乱检索刷次数，或者索性不检索、猜答案。

为此，GraphRAG-R1 设计了一套过程约束奖励机制（Processed-Constrained Rewards），专门用来塑造模型的“好习惯”。

〓 训练框架：会“思考”的检索智能体

论文基于 GRPO（Group Relative Policy Optimization）算法进行改造，赋予模型 Rollout-with-Thinking 能力。

在生成答案的过程中，模型可以通过特殊标记主动暂停推理，调用外部知识图谱检索工具，再将检索结果无缝嵌入后续推理。

检索不再是僵硬的预处理步骤，而是模型思考链条上的一个主动动作。

两大核心奖惩：PRA 与 CAF

如何让模型懂得该检索什么，检索多少，既不遗失信息，也不带来冗余？GraphRAG-R1 设计了两个互补的奖励函数：

PRA（Progressive Retrieval Attenuation，渐进式检索衰减奖励）

  * 作用：惩罚模型的偷懒行为，防浅层检索（shallow retrieval）。

  * 原理：第一次检索给足奖励，鼓励模型迈出第一步；后续每次检索的奖励按指数衰减。这既能驱动模型进行基本的、必要的搜索，又避免它无休止地检索下去。




CAF（Cost-Aware F1，成本感知 F1 奖励）

  * 作用：惩罚模型的冗余推理，防过度思考（over-thinking）。

  * 原理：在 F1 分数的基础上，乘以一个随检索次数增加而衰减的系数。同样答对一道题，用的检索次数越少，奖励越高。这迫使模型学会评估问题难度：简单问题少检索节约成本，复杂问题花费更多的成本去进行推理和检索以更好的得到答案。




两条规矩协同作用，模型自然学会在“查得全”和“查得省”之间找到平衡。

三阶段训练：课程学习思想的应用

为了稳定地注入上述行为规范，GraphRAG-R1 采用了分阶段训练策略：

  * 冷启动阶段：用监督微调（SFT）教会模型基本的输出格式和工具调用语法。

  * 行为塑造阶段：引入 PRA 奖励，集中训练模型主动决策查询时机和频率的行为模式。

  * 智能优化阶段：切换到 CAF 奖励，在保证正确率的前提下，进一步压缩不必要的计算开销。




此外，模型检索回来的不是冗长的文本片段，而是混合图-文本信息，结构化知识图谱的精确实体关系与文本语义细节兼顾，Token 消耗更低，信噪比更高。

实验结果：性能领跑，成本更低

论文在 HotpotQA、MuSiQue、2Wiki、PopQA 等主流多跳问答基准上对 GraphRAG-R1 进行了全面评估，基座模型为 Qwen2.5-7B。

主要结果：越难越强

GraphRAG-R1 在所有数据集上均取得最佳 F1 分数，且在最复杂的多跳数据集上优势最为突出：

  * HotpotQA：F1 比最强基线提升 38.08%

  * MuSiQue：提升 62.43%

  * 2Wiki：提升幅度高达 83.81%

  * PopQA（零样本泛化）：提升 19.96% ，泛化能力出色




消融实验：PRA 与 CAF，缺一不可

  * 移除 PRA 后：模型平均检索次数明显下降，陷入浅层检索，F1 大跌。

  * 移除 CAF 后：检索次数明细上升，出现过度思考，答案质量却未同步提升，计算资源被浪费。




只有 PRA 与 CAF 协同工作，模型才能在检索次数与答案精度之间找到最佳平衡点。

即插即用与成本优势

GraphRAG-R1 的另一大亮点是强兼容性和泛化性。

仅在 HippoRAG2 为检索器的基础上训练一次，迁移到 KGP、ToG、LightRAG 等其他检索器上，依然能带来平均 20% 以上的性能提升（LightRAG 上达 38.37% ）。

成本方面同样具有显著优势。与同样支持多轮推理的 KGP、ToG 相比，GraphRAG-R1 在取得更高 F1 分数的同时，Token 消耗更低，这得益于其按需检索机制与高效的图-文本混合表示。

跨模型泛化：Qwen-Instruct 与 LLaMA-3 上的验证

为验证框架的普适性，论文还在另外两个基座模型上进行了测试。

Qwen2.5-7B-Instruct：相比 base 版本，Instruct 模型在指令遵循和多轮对话上本身更强，但也意味着训练策略需要相应调整。

研究团队在保留原有 GraphRAG-R1 框架的前提下，仅对训练策略、提示模板和推理超参数做了适配调整。

结果显示，GraphRAG-R1 在 HotpotQA、MuSiQue、2Wiki、PopQA 四个数据集上均取得最佳成绩，全面超越基座版本。

即插即用实验同样表明，与 KGP、ToG、LightRAG 等检索器结合后，性能提升依然稳定，其中在 LightRAG 上的平均提升达到 27.99% ，在 G-Retriever 上更高达 45.22%。

LLaMA-3-8B：为进一步验证方法对不同模型的适应性，论文以 LLaMA-3-8B 作为骨干模型重复了主实验。

考虑到该模型在检索调用上的倾向性差异，训练第三阶段额外引入了 PRA 奖励以增强检索驱动力。

最终，GraphRAG-R1 在所有四个数据集上均优于各基线方法，证明该框架对模型架构没有特殊依赖，具备良好的跨模型迁移能力。

总结

GraphRAG-R1 为 GraphRAG 领域探索了一条新路径：用过程约束强化学习，赋予 LLM 自主可控的多跳推理能力。它不仅显著提升了复杂问答的准确率，还通过精巧的奖励设计实现了效率与效果的双赢。

这项工作表明，让大模型学会“如何思考”与让它“记住更多知识”同样重要。该框架不依赖特定图结构或检索器，具备极强的普适性与落地潜力。
