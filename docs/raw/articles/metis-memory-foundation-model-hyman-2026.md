# MemTensor 开源 Metis：把记忆写进模型内部，128K 长文本端到端加速 1.6 倍

> 来源：Hyman的杂货铺（arXiv 2607.26760《Metis: Memory Foundation Model》解读）
> 论文：https://arxiv.org/abs/2607.26760 | GitHub：https://github.com/MemTensor/Metis | HF：IAAR-Shanghai/metis

## 核心主张

Metis 让模型在前向计算中把历史压进**固定大小的内部状态**，自动完成记住、更新、遗忘和调用；128K 历史长度下比每次重读完整上下文快约 1.6 倍。论文把这类模型称为"记忆基础模型"（Memory Foundation Model），Metis 是首个原型。

## 原生记忆的两个条件

1. 模型内部存在跨多轮交互持续保留、不断变化的记忆状态——只保存交互开始后获得的信息；预训练学到的仍是知识
2. 模型能在前向计算中执行记忆操作（记住/更新/遗忘/调用）

关键：预训练固定权重始终冻结，真正随会话变化的是内部记忆状态。写入时系统不知道未来怎么提问，只能提前判断哪些内容值得保留——RAG 用人工设计的切分/检索/重排规则，Metis 通过训练让模型自己完成。

## Metis Block 架构

基于 Qwen3.5 构建，在 Transformer 层中加入 Metis Block，每块两部分：
- **Local Memory Block**（局部记忆）：每层的记忆状态，保存当前会话信息
- **Hyper Memory Block**（超记忆）：记忆更新模块，把本轮信息转换成下一轮状态（训练后冻结）

**写入**：先给当前序列每个位置内部向量打分，选出总重要度达到阈值所需的最少位置（保留信息量随内容变化，不机械截取固定 token 数）；选中表示经独立键/值投影写入稠密记忆矩阵。带门控更新让模型自己决定保留多少旧信息/写入多少新信息。消融：简单线性更新短期记忆操作不差，但较长 LoCoMo 会话任务明显落后。

**读取**：普通注意力处理当前输入，另加记忆注意力分支读记忆状态；专门学习"从历史中找什么"的查询变换（与普通注意力分开，减少无关轮次干扰）；当前轮只读旧状态，新状态用于下一轮，写入不阻塞当前答案。

**代价**：可直接检查的文字变成难以审计的数值状态。

## 训练：不是背答案，而是管理状态

- 27 个公开基准构造 357,137 条主训练样本（约 4.061 亿 token），覆盖四操作：记住（间隔若干轮询问）、更新（新值覆盖旧值）、遗忘（撤销后不得暴露）、反思（组合多事实推理）；每种分明确指令/自然叙述/插入无关对话三种形式
- 609,443 条辅助样本：多事实（相似属性绑定正确对象、只忘撤销项）+ 普通对话（已有记忆不污染无关回答）
- 冻结 Qwen3.5 骨干，只优化新增记忆参数；上线后无梯度下降，写入只需正常推理

## 实验结果

**记忆操作（No Context 区域，最考验内部状态）**：普通 Qwen3.5 无上下文平均 16.87~18.64 分；Metis-4B/9B/27B 分别 56.72 / 57.92 / 73.77。Metis-27B 遗忘得分 77.50（但不能证明旧信息已不可恢复消失）。外部 MemOps 基准更难：Metis-27B 平均 24.76，仍低于完整上下文 Qwen3.5-27B 的 87.90——内部状态存进了可调用信息，但离无损替代原始历史还有很大距离。

**问答**：LoCoMo 无上下文普通 Qwen3.5 接近零，Metis-27B 达 26.74；NextMem 从 17.75 提升到 50.82；完整上下文 Qwen3.5-27B 仍有 78.80。

**端到端延迟（单张 A800，batch=1）**：交叉点在 64K；128K 时生成 32 token 从 14.254s 降到 9.521s（快 1.497 倍），生成 128 token 从 21.404s 降到 13.423s（快 1.595 倍）。原因：Qwen3.5-4B 的 32 层中 24 层用固定状态处理历史，只有 8 层注意力缓存随文本变长。

**会话存储**：32K 历史下完整上下文需保留 1,118.86 MB；Metis 恒定 16.79 MB（相差约 67 倍）。低秩分解：秩 64 vs 完整 1024，四项基准平均 33.10 vs 33.14（恢复率 99.9%），每会话仅 2.11 MB。

**容量上限**：记住虚构用户 40 属性，单次写入超数百词或连续更新时，早期事实准确率持续下降——问题不只是"旧记忆被新记忆覆盖"，每次压缩产生的误差还会在状态变换中累积。

**能力干扰**：写入无关信息后四项通用能力全部下降（Metis-4B vs Qwen3.5-4B）：MMLU-Pro 46.00→40.90（-5.10）、IFEval 76.71→54.53（-22.18）、GSM8K 84.53→78.92（-5.61）、MMMLU 59.90→56.60（-3.30）。IFEval 下降最大——无关记忆影响严格指令遵循。外部记忆"没有取回就不进入模型"的隔离性被打破。

## 结论

两种记忆方式互补：外部文字易于审计、删除、精确引用，完整上下文在关键事实任务仍有明显优势；原生状态体积固定、读取快，适合经常使用无需逐字保存的交互信息。医疗/金融/权限状态等要求可验证事实的场景，单独依赖难以核验的数值状态风险很高。短期更可行方向：原生状态承担快速工作记忆，可审计外部存储保留长期事实与证据。
