# 南大 × 阿里提出TVIR：深度研究Agent迈入图文交错时代

随着大语言模型的快速发展，深度研究智能体（Deep Research Agents）应运而生，它们能够自主进行多步信息检索、推理和生成，产出完整的研究报告。

然而，现有的评测基准和系统几乎都是  以文本为中心  的——它们基于文本连贯性、分析深度和引用支持来评估，却忽视了真实专业报告的一个关键特征：  视觉证据的整合  。

在实践中，高质量的研究报告很少只依赖文字，而是将叙述性分析与图表、图像交织在一起，它们是支撑论点、揭示趋势、辅助理解的  核心证据  。即使有些系统包含视觉元素，也往往将其视为装饰性补充，而非推理的一部分。

近日，南京大学联合阿里巴巴提出了  TVIR  （  T  ext–  V  isual  I  nterleaved  R  eport Generation），一个面向图文交错报告生成的统一基准与智能体框架，首次系统性地评估深度研究智能体的多模态能力。

TVIR: Building Deep Research Agents Towards Text–Visual Interleaved Report Generation

https://arxiv.org/abs/2606.02320

核心问题：现有基准与真实需求之间的错位

现有深度研究基准与真实分析工作的需求之间存在根本性错位。一个能写出流畅文字、但生成不准确、误导性或与上下文脱节的视觉元素的研究智能体，在高风险决策场景中是不可靠的。

更糟糕的是，由于缺乏显式的评估协议，模型倾向于优化“表面上的视觉完整性”——追求美观而非证据严谨性。

解决这一局限需要重新思考深度研究：  它不应被视为纯文本任务，而是一个多模态综合问题  ，文本和视觉必须被联合生成、联合评估。

TVIR-Bench：100 道专家级多模态深度研究任务

TVIR-Bench 是首个专门为端到端多模态研究报告生成设计的综合基准，包含  100 个专家策划的任务  （50 中文 + 50 英文），覆盖 10 个主要领域和 3 个复杂度级别。

任务设计遵循五大核心原则：  角色驱动、需求导向、深度研究、前沿聚焦、多模态整合  ，确保任务锚定真实用户需求，要求实质性分析综合而非简单信息检索。

任务构建采用专家驱动的四阶段流程：

1\.  专家主题提议  ：领域专家提出具有时效性和新颖性的核心主题

2\.  基于 LLM 的任务起草  ：基于核心主题，使用 LLM 生成逻辑连贯、可研究的任务初稿

3\.  多专家审核与修订  ：三位专家从设计合规性、事实准确性、逻辑连贯性和多模态有效性四个维度审核修订

4\.  核查清单编制  ：为每个任务编制评估核查清单，用于系统性验证生成报告的完整性

TVIR-Agent：四阶段分层多智能体框架

TVIR-Agent 是一个专为图文交错报告生成设计的分层多智能体框架，包含四个核心阶段：

3.1  研究驱动的规划

Planner  解析用户任务，迭代调用搜索和网页抓取工具检索相关信息，然后将收集到的信息综合成结构化大纲。每个大纲单元包含：

* 章节标题和摘要

* 规划的视觉需求

* 章节级研究笔记（含引用、来源 URL 和关键发现）

3.2 视觉资源实例化

这一阶段通过两个专门的智能体实例化视觉需求：

* Image Searcher  ：处理肖像、场景、架构图等视觉概念，通过 Google 图片搜索检索候选图像，使用 VQA 工具验证相关性

* Chart Generator  ：处理涉及数据分布或关系的内容，检索相关数据，验证真实性和跨源一致性，生成 Python 绘图代码并在沙盒环境中执行

3.3 上下文感知的顺序写作

Writer  逐章节生成报告。为保持跨章节的连贯性并减少冗余，它基于当前大纲单元和动态更新的全局上下文（包含已生成章节的标题、摘要和子章节结构）进行条件生成。

Writer 同时使用章节级研究笔记作为支撑证据，当证据不足时会调用搜索工具获取额外信息。在生成过程中，Writer 根据视觉资源的描述确定插入点，生成图文交错的 Markdown 内容。

3.4 全局索引整理

Polisher  在报告级别处理引用和图片：首先移除各章节中未被引用的参考文献，然后按 URL 和标准化内容全局去重，重新编号为统一的参考文献列表并更新正文中的引用标记。

最后对全文图片重新编号，按顺序分配图片 ID 和标签，并更新正文中的图片引用。

双路径评估框架：文本 + 视觉

TVIR 提出了一个多维度评估框架，包含  文本评估（TA）  和  视觉评估（VA）  两个互补组件。

文本评估（Textual Assessment）

视觉评估（Visual Assessment）

实验结果：9大系统横评

研究团队评估了 9 个深度研究系统，包括 6 个商业系统和 3 个 TVIR-Agent 变体。

关键发现

1\. TVIR-Agent 整体表现最强

TVIR-Agent（Claude-4.5-Sonnet）取得最佳整体分数，其次是 TVIR-Agent（Qwen3-Max）和 TVIR-Agent（GLM-4.7）。在商业系统中，Manus-1.6 表现最好。

2\. 不同变体各有所长

* TVIR-Agent（GLM-4.7）在文本评估（TA）上得分最高，展现出较强的文本能力

* TVIR-Agent（Claude-4.5-Sonnet）以明显优势取得视觉评估（VA）最高分，展现出卓越的视觉支持和跨模态对齐能力

3\. 引用支持差距显著

在  Citation Support  指标上，TVIR-Agent（GLM-4.7）达到 68.64 分，比最佳商业系统 Claude-4.5-Sonnet w/Search（47.53）高出  21.11 分  。

4\. 任务复杂度影响模式

随着任务复杂度增加，  Instruction Alignment  普遍下降，而  Analytical Depth & Breadth  倾向于提升。这表明复杂任务对多模态协调和长程推理提出了更高要求，但也鼓励更全面、更深入的响应。

结构性错误分析：TVIR-Agent 更可靠

研究团队分析了三类结构性错误：

* 可追溯性错误  ：事实、数据或图表缺乏明确可访问的来源

* 一致性错误  ：内部索引系统失败，如编号缺失或重复

* 完整性错误  ：引用的组件不可用或不完整，如损坏的图表或缺失的图注

结果显示，  TVIR-Agent 变体产生的结构性错误显著少于商业系统  ，表明在引用管理和多模态报告组装方面具有更好的端到端控制能力。

工具使用分析：平衡是关键

不同 TVIR-Agent 变体展现出不同的工具使用模式：

TVIR-Agent（GLM-4.7）  ：搜索和抓取工具使用最频繁，平均有效引用数（AEC）最高达  102.41  。

但在有限的智能体轮次预算下，过度检索可能以牺牲图表生成为代价——尽管平均每个任务规划 8.66 个图表，实际只生成 3.33 个，图表完成率仅 38.45%。

TVIR-Agent（Claude-4.5-Sonnet）  ：采用更平衡的工具使用策略，在保持较高 AEC（86.14）的同时，实现了最高的图表完成率  94.61%  。

这表明 TVIR-Agent 变体的相对优势不仅取决于骨干模型能力，还取决于工具使用在检索和图表生成之间的分配方式。

总结

TVIR 提出了一个面向图文交错报告生成的统一基准与智能体框架，包括专家策划的 TVIR-Bench 基准、在规划和写作全程显式建模视觉证据的 TVIR-Agent，以及覆盖文本和视觉的双路径评估框架。

大量实验表明，TVIR-Agent 取得了强劲的整体表现，在证据支持和跨模态对齐方面优于现有系统，同时也揭示了当前深度研究系统的一个关键局限：  它们在文本综合方面远强于视觉整合  。

我们希望 TVIR 能为未来可信的多模态深度研究智能体奠定基础。
