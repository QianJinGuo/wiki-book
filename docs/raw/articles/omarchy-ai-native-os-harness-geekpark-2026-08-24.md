# 硅谷押注的下一个 Harness，是整个桌面操作系统

> 来源：极客公园（作者：张勇毅，编辑：靖宇，2026-08-24）。Omarchy 4.0（8 月 14 日发布）是一个 AI 原生 Linux 发行版，由 DHH（Ruby on Rails 作者、《重来》作者）开发。核心概念是「系统即 Harness」：把 Agent 所需的工具/权限/状态/反馈直接做进操作系统，让 AI 读得懂、改得动系统本身。8 月 21 日 DHH 宣布成立 Omacom 基金会，首期 800 万美元来自八位赞助人（Michael Dell、Jack Dorsey、Shopify/Stripe 两位 CEO、Cloudflare CEO、Oculus 联合创始人、37signals 两位创始人）。

## 三句话总结

1. **系统即 Harness，Harness 即系统**：Omarchy 把整个桌面环境重写成一个进程 Quickshell（状态栏/启动器/菜单/通知/锁屏全在里面），系统配置全部改成 Lua 脚本，插件就是一个 Git 仓库，外部程序可以直接给 Shell 发指令——系统里每个部件都是文本文件，都能被读、被改、改完立刻看到结果，一个 Agent 需要的工具、权限、状态、反馈四样东西它全有。
2. **AI 可读可写的操作系统**：开机设置阶段可从九家（Claude Code、Codex、Gemini、Grok、Copilot 等）选一家当系统默认 Agent，以独立应用身份运行，授过权会记住，按快捷键即可读配置、改文件、跑命令、看结果。4.0 把镜像压到 6GB 以内，安装快三成，装完不用配任何东西。4.0 发布一周插件市场超 500 个，8 月 19 日办第一届插件大赛。
3. **押注「模型之上、硬件之下」的一层新东西**：对比苹果/微软（Apple Intelligence 和 Copilot 都是按钮，改不了系统，因为封闭系统/签名/沙盒每一层都不让程序碰系统本身），Omarchy 押硬币反面——操作电脑这件事要换主体，从人换成 Agent。靠的不是新技术，是 Unix 五十年前的老规矩「一切皆文件」。800 万美元用途四件事：持有商标、养基础设施、做推广、资助依赖的开源项目（第一笔给了 Hyprland 作者 Vaxry）。

## 主要事实与细节

- **Omarchy 4.0 特性**：可配置的默认编程 Agent 是核心卖点之一；作者本人演示过让 Agent 写一个「看起来像野马车速表」的测速插件，几句话之后插件装上。插件能换掉状态栏一个组件，也能换掉整条状态栏。
- **作者试玩体验**：过去十几年无数次被命令行劝退的人，第一次用自然语言中文就把系统修好，全程没有手动输入一条命令。拆墙的不只是 Agent，另一半功夫在开箱即用（主题、快捷键、常用软件全现成，换一个主题终端/编辑器/浏览器跟着变）。系统菜单有 Learn 入口，快捷键表、Omarchy 手册、Hyprland 和 Arch 文档放手边。
- **历史数据**：去年 10 月单月安装量 15 万次；4.0 发布一周插件市场超 500 个，社区十天写了 1,074 个插件；8 月 19 日项目成立核心团队，不再 DHH 一个人说了算。
- **八位赞助人的动机推测**：戴尔/Oculus 硬件出身，过去两年「AIPC」概念由微软定义，若下一代桌面操作者变成 Agent，戴尔手里就多一条不经过微软的路（4.0 专门给 2026 款 XPS 调了扬声器，Framework 已把它列为官方支持系统）；软件公司六位 CEO 为自家工程师需求更新的平台（Shopify、Stripe、Cloudflare、Block 都养着成千上万开发者，37signals 已宣布三年内把运维和 Ruby 团队全部换过去）+ 下一代应用分发入口（官网和软件源镜像跑在 Cloudflare 上）。文章明言「以上是我的推测，八个人里没有谁这么说过」。
- **定位类比**：作者把 Omarchy 类比为「龙虾 OpenClaw」（同样是个人业余项目，把 Agent 装进电脑、给它真实权限，三个月星数超过 Linux 本身，创始人被 OpenAI 招走，项目交给基金会；顺手把 Mac mini 卖到断货）；以及 2001 年之后的 Mac（Unix 底子 + 好看壳，先征服程序员再征服所有人）。
- **局限性（文章明说半成品）**：Agent 一等公民仍脆弱（Codex 升到 0.149 状态栏用量显示就坏；Gemini 命令行工具改名默认列表就过期；九家模型能力适用范围每周都改，系统级集成意味着系统级脆弱）；门槛只拆一半（AI 替你敲命令行但没替你记快捷键，平铺式窗口管理器学习曲线是英文社区最一致抱怨）；中文是二等公民（输入法引擎要自己装，语音输入基本只认英文）；硬件挑人（Apple Silicon 要靠社区分支绕路，NVIDIA 50 系显卡装完黑屏，连调过音的 XPS 13 都有人报滚动卡顿）。
- **名字来源**：Omarchy 来自 Omakase（日料里的主厨推荐），也是 Rails 一直以来的哲学「别选了，按我配的来」。直到 Omarchy 3 都靠 DHH 个人品味小范围传播，4.0 之后主厨推荐变成自选。
