# 近30家高校机构联合发起，国内首个 Agent 记忆榜单 AML 出炉，谁的 Agent 最不健忘

> 来源：夕小瑶科技说 | 2026-08-12 21:00 北京 | 官网：<http://agentmemories.ai/>

## 摘要

2026-08-12，Agent Memory Leaderboard（AML，记忆之巅排行榜）正式发布首期结果。AML 由清华、北大、人大、上海交大、浙大、复旦、中科大、南大、上海人工智能实验室、中科院自动化所等国内外数十所高校与研究机构联合主办，开源社区 Datawhale 参与。作为业内首个关注 Agent 记忆系统的机制级榜单，上线十天内吸引 136 个团队注册参评，官方站点点击量突破 20 万次。

## 评测机制：聚焦"记忆"本身

评测按两个独立维度组合：类型分文本记忆和代码记忆两条赛道，组别分学术方法榜和商业产品榜。文本赛道考察事实召回、多跳整合、时序理解、记忆治理、个性化、规则执行、安全与隐私；代码赛道看系统能否从历史工程任务中检索并复用调试经验与项目上下文。

AML 的核心设计在于对评测变量的控制：统一提供生成模型和评分模型，将参评方案的主要发挥空间集中在检索与召回环节，从而尽可能单独评估记忆系统本身的能力（而非底层生成模型）。防刷分方面，采用公开子集与私有盲测集相结合，评测分数与代码 Commit 或镜像版本绑定，降低硬编码和针对测试集过拟合的可能性。

## 榜单结果

商业产品榜文本赛道：MemoraX 以 58.0 分位列第一，MemOS 和 NTES-MEMORY-SMART 分列其后。MemoraX 在系统稳定性、信息检索与召回等方面表现突出。

开源方法榜文本赛道：InvMem 以 45.1 分位列第一，Refind 和 ActiveMemoryIndex 紧随其后，Hybrid Search、ChronoHybridMem 等方案也取得靠前成绩。

整体来看，Agent 记忆系统尚未形成单一主流路线，动态记忆索引、混合检索等方向仍在持续演进。AML 官方表示榜单将保持常态化更新，并推出深度解读与技术复盘。
