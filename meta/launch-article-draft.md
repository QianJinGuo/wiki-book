# 《AI工程》开源电子书：如何用AI编撰4000+篇系统化AI知识库

大家好，我是QianJinGuo。

今天想和大家分享一个我持续维护的开源项目：**《AI工程》电子书**（https://jinguo.tech）。这是一个基于4,000+篇一手文章系统编撰的AI工程知识库，覆盖从LLM原理到生产级Agent的全栈内容。

## 为什么做这个项目？

在学习AI工程的过程中，我发现：
1. **信息碎片化**：每天有大量AI文章发布，但缺乏系统性的整理
2. **质量参差不齐**：很多文章缺乏溯源，难以判断可靠性
3. **学习路径缺失**：从入门到专家，缺乏清晰的成长路径

所以我想做一个**每日更新、质量可控、体系完整**的AI工程知识库。

## 项目特色

### 1. 规模与体系
- **2,201篇精选条目**（从4,050篇一手文章中精选）
- **20章5篇**的完整知识体系：
  - 入门篇（AI基础、提示词工程、工具全景）
  - 工程师篇（Agent架构、Harness、记忆管理、MCP、多Agent）
  - 专家篇（云基础设施、安全、MLOps、数据工程）
  - 科学家篇（训练微调、推理优化、多模态、机器人）
  - 大师篇（前沿研究、AI哲学）

### 2. 质量保障
- **每个条目溯源一手原文**：点击即可跳转到原始文章
- **难度标注**：⭐️~⭐️⭐️⭐️⭐️⭐️五级难度
- **每日自动更新**：AI辅助编撰，每日同步最新内容

### 3. 技术亮点
这是一个**技术驱动的内容项目**，内置了：

- **四层RAG检索系统**：
  - Layer 1: 浏览器端IndexedDB搜索（0ms响应）
  - Layer 2: BM25全文检索
  - Layer 3: 讯飞+Vectorize语义搜索
  - Layer 4: Pages Function兜底

- **质量闭环**：每日自动check & eval，入库评分门禁+出口精选门禁

- **三环境部署**：
  - Cloudflare Pages（生产环境）
  - GitHub Pages（静态站点）
  - Docker（本地开发）

### 4. 开源协议
- **内容**：CC BY-SA 4.0（可自由分享、改编，需注明出处）
- **代码**：MIT协议
